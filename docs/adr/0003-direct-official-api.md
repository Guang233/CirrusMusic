# ADR-0003 · 网易云官方 API 内置直连

- 日期：2026-09-26
- 状态：官方 API 直连为维护者已明确约束；内部适配分层为 Proposed
- 负责人：后端／维护者

## 背景

维护者拥有官方 API 资料，产品要求用户安装即可使用。用户可配置第三方 API 服务不是本项目需求。

## 决策

Cirrus C++ 后端直接调用官方 API，内置 EndpointRegistry、ProtocolSigner、HttpTransport、DTO 与 DomainMapper。协议参数、签名／加密、Cookie 和错误码止于适配层，不进入 QML。

生产端点受应用版本管理；测试通过专用构建的依赖注入替换 transport。默认不提供 API 地址设置，不捆绑 Node.js 常驻服务，不自建业务代理。

## 备选

- 用户自部署第三方 API：与明确需求不符，排除。
- 自建统一代理服务：引入运维、隐私和单点故障，排除。
- QML 直接拼 HTTP／签名：秘密暴露与契约散落风险高，排除。

## 后果

终端用户使用简单，客户端承担官方协议兼容和更新责任。已依据维护者指定的 api-enhanced 固定版本完成静态审计；它只作为协议参考，不作为 Node 运行依赖。无真实响应证据的部分可以做 fake 后端，但不能编造服务能力。v2 token 的浏览器 SDK 依赖需另行决策，不默认嵌入 WebEngine。

## 验证与复议

M0 完成核心 operation 契约、签名向量和真实来源验证。官方协议变化只优先替换适配器，不修改用户部署模式。任何增加外部业务服务的方案都需维护者明确批准的新 ADR，不能以调试方便悄悄改变架构。

补充：审计数据的离线 Python 校验器仅为开发工具；所有产品协议、网络、会话和业务逻辑使用 C++/Qt。
