# 首页设计

状态：**第二版**（2026-10-31）。代码在 `ui/app/HomePage.qml`、`TodayCard.qml`、`FmCard.qml`、`HomeSection.qml`、`ChartCard.qml`；外壳和侧边栏见 [shell.md](shell.md)。

已定（维护者，2026-10-31）：相似歌曲不放首页；首页要多放推荐内容（因此 D5 推翻，登录后也有新碟，另加推荐歌单、榜单、热门歌手）。D1–D4 按建议做了，待维护者确认。

第一版反馈后的修改：加推荐内容（§2）；FM 播放时封面缩到 72 px，与暂停按钮之间留出 24 px。

## 1. 首页做什么

用户打开应用，第一件事通常是"放点什么"。首页只做这一件事：**一次点击开始听，而且听的是为这个人、为今天准备的内容。**

所以首页和发现页分开：

| | 首页 | 发现 |
| --- | --- | --- |
| 问题 | 我现在听什么？ | 还有什么可听？ |
| 内容 | 今日推荐、私人 FM、最近听过、每日推荐歌单，以及各类推荐的一行预览（推荐歌单、榜单前三、新碟、热门歌手） | 完整的榜单、歌单分类与精品歌单、新碟、歌手、相似推荐 |
| 依据 | 账号（未登录时退化） | 公共目录 |

首页不放轮播横幅（后端没有横幅接口，也不想要广告位）、不放问候语（"早上好，xx"不帮用户做任何事）、不做无限滚动。推荐区块每个只放一行，"查看全部"进发现页。

## 2. 可用数据

只用后端已有的读取（`docs/api/`），不编造字段：

| 区块 | 后端读取 | 需要登录 | 备注 |
| --- | --- | --- | --- |
| 今日推荐 | `DailyRecommendations`（[discovery-and-fm.md](../../api/discovery-and-fm.md)） | 是 | 每首歌带推荐理由（按歌曲 ID 对应，可能没有）；读取不强制服务端换一批 |
| 私人 FM | `PersonalFm` + 已有的 FM 连续播放 | 是 | 首页不预取，点播放才开始 |
| 最近听过 | `recentSongs`（[cloud-history-reads.md](../../api/cloud-history-reads.md)） | 是 | 网易云的云端记录，取前 6 首 |
| 每日推荐歌单 | `DailyRecommendedPlaylists`（[daily-recommended-playlists.md](../../api/daily-recommended-playlists.md)） | 是 | 一行卡片 |
| 推荐歌单 | `RecommendedPlaylists`（personalized，[playlist-discovery-reads.md](../../api/playlist-discovery-reads.md)） | 否 | 一行卡片 |
| 榜单 | `ChartsWithPreviews`（[chart-reads.md](../../api/chart-reads.md)） | 否 | 榜单是歌单；预览是服务端给的文字（歌名、歌手），不是歌曲，取前 3 条 |
| 新碟上架 | `LatestAlbums`（[discovery-browse-reads.md](../../api/discovery-browse-reads.md)） | 否 | 一行卡片 |
| 热门歌手 | `PopularArtists`（同上） | 否 | 一行圆形头像 |

顺序：今日 + FM → 最近听过 → 每日推荐歌单 → 推荐歌单 → 榜单 → 新碟上架 → 热门歌手。未登录时没有今日推荐内容（换成登录邀请）、FM、最近听过和每日推荐歌单。

官方客户端首页的"私人雷达""心动模式"后端没有：心动模式在 [selected-endpoints.md](../../api/selected-endpoints.md) 里只是候选，私人雷达没有对应接口。

## 3. 视觉方向

MD3 Expressive 外壳语言，颜色只用动态配色角色。大部分区块克制处理，力气只花在一个地方：**顶部的"今日"**。

### 3.1 标志元素：日期数字

网易云的每日推荐一直用日历上的日期做图标，用户认得它。首页顶部把这个日期放大成一块版面：

- 日期数字用 MiSans，112 px（窄窗口 72 px），字重 200，`onPrimaryContainer`；行高压到字号的 0.9，因为 MiSans 的行框比数字高得多。整页只有这一处大字。
- **字重表示状态（D1）。** 当前播放的歌属于今日推荐、且不是私人 FM 时，数字的字重弹到 630；离开时回到 200。用 `slowEffects` 弹簧，可打断。旁边的日期文字按 630 字重的宽度定位，变粗时不跟着移动。用到了 MiSans 无级字重轴（[README §4.2](../README.md)）；换成系统字体时字体有对应字重就变，没有就不变。
- 减少动态效果时字重直接切换。

### 3.2 颜色

| 位置 | 容器 | 内容 |
| --- | --- | --- |
| 页面底色 | `surface` | `onSurface`、`onSurfaceVariant` |
| "今日"卡片 | `primaryContainer` | `onPrimaryContainer`；次要文字不透明度 0.8 |
| 私人 FM 卡片 | `surfaceContainerHigh` | `onSurface`、`onSurfaceVariant`；电台图标 `tertiary` |
| 歌曲行 | `surfaceContainer`（分段列表） | `onSurface` |

私人 FM 原定 `tertiaryContainer`。实测 2025 规范的暗色方案里它比 `primaryContainer` 亮得多，FM 卡片反而抢过"今日"，所以改成中性容器，只留图标的 tertiary。

### 3.3 字体层级

全部是 MiSans，经 `Theme.type.*` 取；只有日期数字用 `Fonts.font(weight, size)`。

| 用途 | 样式 |
| --- | --- |
| 日期数字 | 112／72 px，字重 200 ↔ 630 |
| 月份与星期、"今日推荐 · 15 首" | `titleMedium` |
| 第一首歌名 | `bodyLarge`；推荐理由 `bodyMedium` |
| 区块标题 | `titleLarge` |
| FM 标题 | `titleLarge`（横条里 `titleMedium`） |

### 3.4 形状

- "今日"和 FM 卡片：`Theme.shape.extraLarge`；FM 横条 `large`。
- 今日卡片右侧：前 4 首歌的封面叠成一摞，每张 `large` 圆角，第一首在最前；依次错开 24 px、下移 6 px、旋转 0°／4°／8°／12°，越往后越淡。不做异形遮罩（D2）。
- 播放按钮：今日卡片用 `Filled`、`Medium` 的文字按钮（"播放"／"暂停"）；FM 用迷你播放条同款图标按钮，播放中变方形，加载时显示加载指示器。

## 4. 布局

内容列最宽 1200 px，更宽时居中（D4）；左右至少 24 px。区块间距 40 px。

### 4.1 宽（内容列 ≥ 792）

```text
┌──────────────────────── primaryContainer ───────────────┐ ┌─ FM 280 ──────┐
│  31   10月 · 星期六                     ┌──┐             │ │ 📻        (▶) │
│       今日推荐 · 15 首                 ┌┤  ├┐┐            │ │               │
│                                        ││  │││            │ │               │
│  第一首《回声》                        └┤  ├┘┘            │ │ 私人 FM        │
│  根据你喜欢的赤色回声推荐                └──┘             │ │ 按你的口味一直放下去│
│  (▶ 播放)  全部 15 首 →                                  │ │               │
└──────────────────────────────────────── 高 280 ─────────┘ └───────────────┘

最近听过                                                        查看全部 →
┌────────────────────────────┐ ┌────────────────────────────┐
│ 6 首，两列分段列表，每列 3 行  │ │                            │
└────────────────────────────┘ └────────────────────────────┘

每日推荐歌单                                                    查看全部 →
┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐   一行，卡片最小 176 px，列数随宽度
```

- FM 播放时，卡片左上换成当前歌曲的封面（72 px），右上是暂停和下一首，底部是歌名和"私人 FM · 歌手"。
- 歌单、新碟、歌手各一行（卡片最小 176，歌手 144），多出的不显示，靠"查看全部"进入发现页；桌面上横向滚动不顺手，不做。
- 榜单卡片：SurfaceContainer、large 圆角，左上 72 px 封面，右边榜名（titleMedium）和更新频率（bodySmall）；下面三行"名次 歌名 · 歌手"，名次用 Primary（这里的编号是真实名次）。每张最小 260 宽，宽窗口一行四张。点卡片打开榜单（歌单详情）。
- 卡片宽 560 以下时不显示封面堆。

### 4.2 中等（内容列 < 792）

FM 变成卡片下方一条 72 px 高的横条（图标、"私人 FM"、播放按钮）；最近听过变单列 6 行。

### 4.3 窄（窗口 < 600）

日期数字 72 px，卡片高 200，不显示"第一首"两行和封面堆，只留日期和按钮。

### 4.4 未登录

"今日"卡片保留日期（不会变粗），文字改为"登录后，这里每天都有一组为你挑的歌。私人 FM 也需要登录。"，按钮"扫码登录"（打开登录对话框）；没有 FM 卡片、最近听过和每日推荐歌单，其余推荐区块照常。登录过期时文字改为"登录已过期，重新扫码登录后恢复今日推荐和私人 FM。"

## 5. 交互

| 对象 | 操作 | 结果 |
| --- | --- | --- |
| 今日卡片 | 点卡片、"全部 15 首" | 打开每日推荐页 |
| 今日卡片 | 播放 | 从第一首播放今日推荐；正在播放今日推荐时变为暂停 |
| 今日卡片 | 悬停 | 状态层；封面堆错开到 32 px、旋转各加 2°（`defaultSpatial`） |
| FM | 播放 | `App.player.startFm()`；FM 播放中变为暂停 |
| FM | 下一首 | 只在 FM 模式出现；等待下一首时禁用 |
| 歌曲行 | 单击 | 以这个区块的 6 首为队列，从这首开始播放 |
| 卡片 | 单击 | 打开歌单／专辑详情 |
| 区块标题 | "查看全部" | 最近听过 → 音乐库的"最近播放"；推荐歌单、榜单、新碟、歌手 → 发现页（每日推荐歌单没有"查看全部"，一行就是全部） |
| 页面 | F5 | 重新读取所有区块。不放刷新按钮，也不叫"换一批"（服务端不保证换内容） |

## 6. 状态

各区块按自己的读取分别加载、分别失败（`HomeSection`）：

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 区块显示骨架（歌曲是三条圆角块，歌单是一排方块）；今日卡片保留日期，只把两行文字换成占位条 |
| 区块到达 | 内容淡入并上移 16 px（`standardDefaultSpatial`）；减少动态效果时直接出现 |
| 单个区块失败 | 区块位置一行："最近听过没有加载出来" + "重试"；离线时前面加"网络不可用，" |
| 今日推荐失败 | 卡片里同样一句话 + "重试" |
| 全部失败（通常是离线） | 整页："连不上网易云音乐" / "检查网络后重试。" + "重试" |
| 今日推荐为空 | "今天的推荐还没生成，稍后刷新试试。"，不显示播放按钮 |
| 最近听过为空 | 整块隐藏 |
| 第一首没有推荐理由 | 第二行显示歌手名；理由按服务端原样显示 |
| 未登录、登录过期 | 见 §4.4 |

## 9. 展示层

`ui/presentation/home_page_model.*`：

- `DailySongsPageModel` 增加 `lead`（第一首，`SongItem`）和 `coverKeys`（前 4 张封面）。
- `RecentSongsModel`：`limit`（默认 6）、`songs`；未登录为 `SignedOut`。数据源 `LibrarySource::recentSongs(limit)`。
- `ShelfModel`：`shelf`（`Feed.DailyPlaylists`／`RecommendedPlaylists`／`NewAlbums`／`PopularArtists`）、`items`；数据源 `CatalogSource::shelf()`，`DailyPlaylists` 未登录为 `SignedOut`。
- `ChartsModel`：`charts`（`ChartListModel`，角色 `key`、`title`、`updateLabel`、`coverKey`、`previews`）；数据源 `CatalogSource::charts()`。假数据的四个榜单是用示例歌曲拼的歌单，可以打开。
- `SongInfo`／`SongItem` 增加 `reason`，`SongListModel` 增加 `reason` 角色和 `containsCurrent`（当前歌曲在不在这个列表里）。
- 首页不再使用 `HomePageModel`。（发现页实现后 `FeedPage` 已删除，`HomePageModel` 没有页面用了，见 [discover.md §8](discover.md)。）
- `ChartsModel` 后来加了 `others`（没有预览的榜单），首页只用 `charts`；"查看全部"改为打开发现页的对应标签（`shell.openDiscover(tab)`）。
