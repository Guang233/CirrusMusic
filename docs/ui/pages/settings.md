# 设置页设计（待评审，2026-11-03）

现在的设置页是阶段 3 早期的原型（`ui/app/SettingsPage.qml`），只有账号、外观、窗口、歌词四节，版式是"标签在上、按钮组在下"，没经过设计。本文把它补全为正式页面：内容按后端现在能做的来，没有的写明"等后端"。

## 1. 能设置什么

| 分组 | 项 | 状态 | 数据 |
| --- | --- | --- | --- |
| 账号 | 头像、昵称；登录／退出登录 | 现有 | `App.session` |
| 播放 | 音质：标准／极高／无损／Hi-Res | **新增** | 后端 `AudioQuality`（standard／exhigh／lossless／hires），取流时传入，默认 Standard；拿不到所选音质时服务器给可用的最高档（`actualQuality`）。展示层加 `App.settings.audioQuality`，传给播放 |
| | 输出设备 | 等后端 | `QAudioOutput` 属于后端播放器，界面不能直接换设备 |
| | 启动时恢复上次的播放队列 | 等后端 | 后端已有队列持久化（`listening-state-persistence`），默认关、没接产品入口 |
| 歌词 | 显示翻译、显示音译 | 现有 | `App.settings` |
| 外观 | 明暗：跟随系统／亮色／暗色 | 现有 | |
| | 主题色来源：系统强调色／跟随封面／固定 | 现有；"固定"**加色板** | `Theme.fixedSeed` 已有，没存设置、没有入口（现在固定为 MD3 基准紫）。加 `App.settings.fixedSeed` |
| | 配色风格 | **新增**（UQ-04） | `Theme.variant` 已有 9 种，`App.settings.variant` 已存，没有入口 |
| | 字体：内置 MiSans／系统／自定义（选字体族） | 现有 | |
| | 减少动态效果 | 现有 | |
| 窗口与系统 | 窗口装饰、关闭主窗口时、使用独立显卡 | 现有 | |
| | 系统媒体控制（MPRIS：媒体键、桌面的播放控件） | 等后端 | 后端有源码，默认不编译，桌面上没验证 |
| 存储与隐私 | 缓存：占用多少、清除 | **新增** | 后端 `ResourceCacheService::usage()`／`clear()`：歌曲信息和歌词（上限 128 MiB）、封面（512 MiB）；只清缓存，不动登录、音乐库、听歌记录。展示层加 `App.cache`（`usage`、`clear()`），假实现给固定数字 |
| | 搜索历史：清除 | **新增** | `App.settings.searchHistory`（现在只能在搜索下拉里逐条删） |
| | 向网易云上报听歌记录 | 等后端 | 后端有显式上报，自动上报的时机没接 |
| 键盘快捷键 | 只读列表 | **新增** | 见 §4 |
| 关于 | 名称、版本、非官方声明、第三方许可 | **新增** | MiSans 的许可要求在软件里注明使用了它（README §4.2），现在没有地方注明 |

"等后端"的项先不显示（S7），后端做好后按本文的位置加上。

## 2. 版式

```text
设置                                                         ← 页面标题（PageScaffold）

 账号            ┌────────────────────────────────────────────┐
 播放            │ (头像)  雾港听众                [退出登录] │ ← 账号卡
 歌词            └────────────────────────────────────────────┘
 外观
 窗口与系统        播放                                          ← 分组标题 titleSmall Primary
 存储与隐私      ┌────────────────────────────────────────────┐
 键盘快捷键      │ 音质                         [ 极高   ▾ ]  │ ← 行：标题＋说明在左，控件在右
 关于            │ 没有这一档时用能拿到的最高音质；无损和…     │
   ↑             ├────────────────────────────────────────────┤
 章节索引         │ ...                                         │
 （宽窗口才有，    └────────────────────────────────────────────┘
  跟随滚动高亮）
                  外观
                 ┌────────────────────────────────────────────┐
                 │ 明暗              [跟随系统|亮色|暗色]      │
                 ├────────────────────────────────────────────┤
                 │ 主题色来源   [系统强调色|跟随封面|固定]     │
                 │   ● ● ● ● ● ● ● ●   ← 选"固定"时展开色板    │
                 ├────────────────────────────────────────────┤
                 │ 配色风格                     [ 标准   ▾ ]  │
                 └────────────────────────────────────────────┘
```

- **一页长列表，宽窗口加章节索引（S1）**。内容列最宽 720，左对齐在页面边距内。内容区宽度 ≥ 1040 时，左边是固定不动的章节索引（列表项，当前可见的分组高亮，点击平滑滚到该组）；窄了索引收起，只剩一列。设置总共二十来项，一页能扫完，不需要"先选分类再看内容"的两栏。
- **分组列表（S2）**：每组是一块 SurfaceContainerLow 的色调卡片，组内各行之间留 2 px 间隙（露出背景）。整组外角 large（16）、组内各行相邻处 extraSmall（4），即 MD3 Expressive 的分段列表。不用阴影，也不画分隔线。
- **行**：左边是标题（bodyLarge）和说明（bodyMedium、OnSurfaceVariant，可多行），右边是控件。行高至少 56（只有标题时）／72（带说明）。控件三种：
  - 开关：`Switch`，点整行也能切换。
  - 2–3 个短选项：`ConnectedButtonGroup`（单选），如明暗、窗口装饰。
  - 选项多或要说明的：Outlined 按钮显示当前值＋▾，点击（或点整行）弹出 `Menu`，菜单项带说明文字。用于音质、配色风格、字体族。
  - 不需要新控件。行和分组卡片做成页面内组件，如果别的页面以后也用，再提到 `Cirrus.Components`。
- **按钮型操作**：清除缓存、清除搜索历史放在行右边，用 Text 按钮；会删数据的先弹确认对话框。
- **账号卡**：头像 56、昵称 titleMedium；游客显示"未登录"和 Filled"登录"按钮，已登录显示 Outlined"退出登录"。会员等级之类的信息后端没有，不显示。
- **色板**：选"固定"时，"主题色来源"一行向下展开（`standardFastSpatial`），出现 8 个圆形色块（40，选中的外圈 2 px OnSurface 并显示对勾）。色块是预设的种子色，取色环上分散的 8 个色相，包括 MD3 基准紫。不做任意取色器。
- **配色风格**：菜单里 5 项，各带一句说明：
  - 标准（TonalSpot，默认）
  - 表现力（Expressive）
  - 鲜明（Vibrant）
  - 中性（Neutral）
  - 单色（Monochrome）

  其余 4 种（Content、Fidelity、Rainbow、FruitSalad）适合按图片取色，跟设置的场景重复或太花，不放。
- **关于**：应用图标、"Cirrus Music"、版本号。说明文字："非官方客户端，与网易云音乐没有关联。"另有"第三方许可"按钮，打开对话框，列出用到的开源组件及其许可：Qt、MiSans、Material Symbols、m3shapes、material-color-utilities，以及其他按实际依赖补全。

## 3. 行为

- 改动立即生效并保存，没有"保存"按钮。需要重启才生效的项（独立显卡）在说明里写明，改后不另外提示。
- 音质改动从下一首开始生效，当前歌曲不重新加载。后端还没有"换音质并保持播放位置"，这一点写在说明里。
- 清除缓存：确认对话框"清除缓存？"／"封面、歌曲信息和歌词会在用到时重新下载。不影响登录、音乐库和听歌记录。"。清除后行内数字更新，提示条显示"已清除缓存"。
- 清除搜索历史：先弹确认对话框，确认后清除。提示条没有操作按钮，做不了撤销。
- 入口：侧边栏底部的齿轮（现有），新增 Ctrl+,（桌面应用的惯例）。关闭对话框里"不再询问（可以在「设置」里更改）"不变。

## 4. 键盘

- Tab 依次经过：章节索引（一个停留点，↑／↓ 移动，Enter 跳到该组），然后各行的控件。
- 单选按钮组改成一个 Tab 停留点，←／→ 切换选项，和标签栏、纸片行一致。改在 `ConnectedButtonGroup`（`exclusive` 时），所以评论页的排序按钮也一起改。维护者已同意键盘操作按建议来，这一条按此执行。
- 开关行：焦点在开关上，Space 切换。菜单行：焦点在按钮上，Enter／Space 打开菜单。
- **快捷键一节**是只读的，按"全局／页面／播放"分组列出，每行左边是动作，右边是按键（键帽样式：SurfaceContainerHighest、圆角 small、labelLarge）。现有的有：
  - 全局：Ctrl+K／Ctrl+F 搜索；Alt+←／Alt+→ 后退／前进；Esc 返回；Ctrl+Q 退出。
  - 页面：Ctrl+PageUp／PageDown 切换标签；F5 刷新首页；Ctrl+S 保存歌单顺序。
  - 列表：↑／↓、Enter 等，写成一句说明，不逐条列。
- **播放快捷键现在一个都没有（S6）**。建议随设置页一起加上，参照网易云 PC 客户端的习惯：
  - Ctrl+P：播放／暂停；
  - Ctrl+← ／ Ctrl+→：上一首／下一首；
  - Ctrl+↑ ／ Ctrl+↓：音量加／减；
  - Ctrl+L：喜欢当前歌曲。

  焦点在输入框里时，Ctrl+←／→ 留给输入框（按词移动光标）。系统级的全局快捷键（窗口不在前台时也生效）在 Wayland 上要走 portal，以后再做。

## 5. 不做的

- 下载、下载目录：后端没有下载。
- 均衡器、音量均衡、无缝播放、淡入淡出：播放后端不支持（`docs/adr/0004-playback-backend.md`）。
- 桌面歌词：放到播放页（阶段 4）之后再考虑。
- 代理：用系统代理设置。
- 界面语言：只有中文。
- 开机自动启动（S8）：以后和托盘一起做（Linux 写 XDG autostart 文件，其他平台各不同）。
- 歌词字号、对齐等播放页的显示选项：等播放页（阶段 4）设计时一起定，放在播放页里，不在这里。
