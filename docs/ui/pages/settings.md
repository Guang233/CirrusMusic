# 设置页设计（已评审，2026-11-04）

**维护者已定**：S1–S8 按建议。另外要求设置项的代码保证可扩展（§7）。

现在的设置页是阶段 3 早期的原型（`ui/app/SettingsPage.qml`），只有账号、外观、窗口、歌词四节，版式是"标签在上、按钮组在下"，没经过设计。本文把它补全为正式页面：内容按后端现在能做的来，没有的写明"等后端"。

## 2. 版式

```text
设置                                                         ← 页面标题（PageScaffold）

 账号            ┌────────────────────────────────────────────┐
 播放            │ (头像)  雾港听众                [退出登录] │ ← 账号卡
 歌词            └────────────────────────────────────────────┘
 外观
 窗口与系统        播放                                          ← 分组标题 titleSmall Primary
 存储与隐私      ┌────────────────────────────────────────────┐
 键盘快捷键      │ 音质                         [ 极高   ▾ ]  │ ← 行：标题＋说明在左，控件在右
 关于            │ 没有这一档时用能拿到的最高音质；无损和…     │
   ↑             ├────────────────────────────────────────────┤
 章节索引         │ ...                                         │
 （宽窗口才有，    └────────────────────────────────────────────┘
  跟随滚动高亮）
                  外观
                 ┌────────────────────────────────────────────┐
                 │ 明暗              [跟随系统|亮色|暗色]      │
                 ├────────────────────────────────────────────┤
                 │ 主题色来源   [系统强调色|跟随封面|固定]     │
                 │   ● ● ● ● ● ● ● ●   ← 选"固定"时展开色板    │
                 ├────────────────────────────────────────────┤
                 │ 配色风格                     [ 标准   ▾ ]  │
                 └────────────────────────────────────────────┘
```

- **一页长列表，宽窗口加章节索引（S1）**。内容列最宽 720，左对齐在页面边距内。内容区宽度 ≥ 1040 时，左边是固定不动的章节索引（列表项，每项前面是分组的图标，放在彩色圆底上。配色照 Android 16 设置首页：用 Material 静态色板（`Theme.staticPalette`，不随主题种子变），圆底取色调 90（暗色 80），图标取 30；相关的分组共用一个色相：账号青、播放与歌词粉、外观橙、存储与隐私黄、窗口与系统／快捷键／关于灰；当前可见的分组高亮，点击平滑滚到该组）；窄了索引收起，只剩一列。设置总共二十来项，一页能扫完，不需要"先选分类再看内容"的两栏。
- **分组列表（S2）**：每组是一块 SurfaceContainerLow 的色调卡片，组内各行之间留 2 px 间隙（露出背景）。整组外角 large（16）、组内各行相邻处 extraSmall（4），即 MD3 Expressive 的分段列表。不用阴影，也不画分隔线。
- **行**：左边是标题（bodyLarge）和说明（bodyMedium、OnSurfaceVariant，可多行），右边是控件。说明只用一句短话讲这一项本身，不解释原理，也不写注意事项（维护者 2026-11-04 要求）；标题已经说清楚的项不写说明。行高至少 56（只有标题时）／72（带说明）。控件三种：
  - 开关：`Switch`，点整行也能切换。
  - 2–3 个短选项：`ConnectedButtonGroup`（单选），如明暗、窗口装饰。
  - 选项多或要说明的：Outlined 按钮显示当前值＋▾，点击（或点整行）弹出 `Menu`，菜单项带说明文字。用于音质、配色风格。
  - 不需要新控件。行和分组卡片做成页面内组件，如果别的页面以后也用，再提到 `Cirrus.Components`。
- **按钮型操作**：清除缓存、清除搜索历史放在行右边，用 Text 按钮；会删数据的先弹确认对话框。
- **账号卡**：头像 56、昵称 titleMedium；游客显示"未登录"和 Filled"登录"按钮，已登录显示 Outlined"退出登录"。会员等级之类的信息后端没有，不显示。
- **色板**：选"固定"时，"主题色来源"一行向下展开（`standardFastSpatial`），出现 8 个圆形色块（40，选中的那个缩小，外面套一圈 2 px OnSurface 的环；不显示对勾，因为没有一种颜色在所有色块上都看得清）。色块是预设的种子色，取色环上分散的 8 个色相，包括 MD3 基准紫。末尾第 9 个是"自定义"色块（S10，2026-11-08 维护者要求，改掉原来"不做任意取色器"的决定）：没选自定义色时显示调色板图标，选了就显示那个颜色并带选中环；点它打开"自定义主题色"对话框：
  - 上方大圆点和色值；两条渐变滑块：色相（彩虹）、色彩度（灰 → 鲜艳）；下方"色值"输入框（#RRGGBB，输入合法时同步滑块）。MD3 从种子色生成配色只用色相和色彩度，所以不做二维取色板；色值里的明暗保留下来，滑块只改色相和色彩度。
  - 调色时整个界面实时换配色；"确定"保存，"取消"、Esc 恢复原来的颜色和来源。
  - 渐变轨道是 `Slider` 的新属性 `trackColors`（controls.md §6）；HCT 换算用 `Theme.hct()`、`Theme.hctOf()`。
- **配色风格**：菜单里 5 项，各带一句说明：
  - 标准（TonalSpot，默认）
  - 表现力（Expressive）
  - 鲜明（Vibrant）
  - 中性（Neutral）
  - 单色（Monochrome）

  其余 4 种（Content、Fidelity、Rainbow、FruitSalad）适合按图片取色，跟设置的场景重复或太花，不放。
- **关于**：应用图标、"Cirrus"、版本号。说明文字："非官方客户端，与网易云音乐没有关联。"另有"第三方许可"按钮，打开对话框，列出用到的开源组件及其许可：Qt、MiSans、Material Symbols、m3shapes、material-color-utilities，以及其他按实际依赖补全。

## 3. 行为

- 改动立即生效并保存，没有"保存"按钮。需要重启才生效的项（独立显卡）在说明里写明，改后不另外提示。
- 音质改动从下一首开始生效，当前歌曲不重新加载。后端还没有"换音质并保持播放位置"，这一点写在说明里。
- 清除缓存：确认对话框"清除缓存？"／"封面、歌曲信息和歌词会在用到时重新下载。不影响登录、音乐库和听歌记录。"。清除后行内数字更新，提示条显示"已清除缓存"。
- 歌曲缓存：行内"听过的歌，已占用 1.3 GB"，"清除"先弹确认对话框"清除歌曲缓存？"／"听过的歌会在再听时重新下载。不影响登录、音乐库和听歌记录。"；正在播放的歌等它不再播放后删除。
- 歌曲缓存上限（S9）：滑块（0.5–50 GB，步长 0.5）加一个窄的输入框（单位 GB，接受一位小数），两者同步；输入框回车或失去焦点时生效，超出范围就夹到范围内。
- 清除搜索历史：先弹确认对话框，确认后清除。提示条没有操作按钮，做不了撤销。
- 入口：侧边栏底部的齿轮（现有），新增 Ctrl+,（桌面应用的惯例）。关闭对话框里"不再询问（可以在「设置」里更改）"不变。

## 4. 键盘

- Tab 依次经过：章节索引（一个停留点，↑／↓ 移动，Enter 跳到该组），然后各行的控件。
- 单选按钮组改成一个 Tab 停留点，←／→ 切换选项，和标签栏、纸片行一致。改在 `ConnectedButtonGroup`（`exclusive` 时），所以评论页的排序按钮也一起改。维护者已同意键盘操作按建议来，这一条按此执行。
- 开关行：焦点在开关上，Space 切换。菜单行：焦点在按钮上，Enter／Space 打开菜单。
- **快捷键一节**是只读的，按"全局／页面／播放"分组列出，每行左边是动作，右边是按键（键帽样式：SurfaceContainerHighest、圆角 small、labelLarge）。现有的有：
  - 全局：Ctrl+K／Ctrl+F 搜索；Alt+←／Alt+→ 后退／前进；Esc 返回；Ctrl+Q 退出。
  - 页面：Ctrl+PageUp／PageDown 切换标签；F5 刷新首页；Ctrl+S 保存歌单顺序。
  - 列表：↑／↓、Enter 等，写成一句说明，不逐条列。
- **播放快捷键现在一个都没有（S6）**。建议随设置页一起加上，参照网易云 PC 客户端的习惯：
  - Ctrl+P：播放／暂停；
  - Ctrl+← ／ Ctrl+→：上一首／下一首；
  - Ctrl+↑ ／ Ctrl+↓：音量加／减；
  - Ctrl+L：喜欢当前歌曲。

  焦点在输入框里时，Ctrl+←／→ 留给输入框（按词移动光标）。系统级的全局快捷键（窗口不在前台时也生效）在 Wayland 上要走 portal，以后再做。

## 7. 扩展：加一个设置项

设置会一直增加，所以加一项要尽量少动地方（维护者 2026-11-04 要求）：

1. **存储**：在 `ui/presentation/app_settings.h` 里加一行 `CIRRUS_SETTING(类型, 名字, setter, "分组/键", 默认值)`，上面用注释说明取值的含义。宏会生成属性、读写函数和 `名字Changed` 信号（moc 能展开它），读写走同一个 `QSettings`，值没变时不写也不通知。键会写进用户的配置文件，以后改属性名时键保持不变。
2. **显示**：在对应分组的文件（`ui/app/settings/*Settings.qml`）里加一行设置项。按控件选类型：
   - `SwitchSetting`：开关，`value` 加 `onSwitched`。
   - `ChoiceSetting`：2–3 个短选项，`options: [{value, text}]`、`value`、`onChosen`。
   - `MenuSetting`：多个选项，或选项需要说明，`options: [{value, text, description}]`。
   - `ActionSetting`：一个操作按钮，`actionText` 加 `onTriggered`。
   - `SliderSetting`：范围内的数值，`from`、`to`、`stepSize`、`value`、`onMoved`，`format` 决定旁边显示的数值文字。
   - `SettingRow`：其他样式，自己写 `trailing`。

   每种都有 `text`、`supportingText`。依赖别的设置才出现的项用 `shown:`，有折叠动画；这台机器上永远没有的项用 `visible:`。分组自动处理首末行的圆角和隐藏行的间隙。
3. **生效**：影响主题的在 `Main.qml` 里加一个 `Binding`；影响播放等后端行为的由对应的展示层对象读取。
4. **新分组**：新建 `ui/app/settings/XxxSettings.qml`（根元素是 `SettingsGroup`，设 `title`），在 `SettingsPage.qml` 的 `groups` 里加一行，再加进 `ui/app/CMakeLists.txt`。左侧索引从分组自动生成。
5. **快捷键**：在别处加 `Shortcut` 后，在 `ShortcutSettings.qml` 的列表里补一行。

## 8. 实现进度（2026-11-04）

已按本文实现。

- **展示层**：
  - `AppSettings` 改成一行一项（§7），新增 `audioQuality`（默认极高）和 `fixedSeed`。
  - 新增 `App.cache`（`CacheStatus`：`bytes`、`limitBytes`、`clearing`、`refresh()`、`clear()`、`cleared(ok)`），数据源是 `CacheSource`（`usage`、`clear`）。假实现固定 184.5 MB，上限 640 MB（128 + 512 MiB）。
  - `Formatter.bytes()`。
  - 应用版本取自 CMake 的 `PROJECT_VERSION`。
  - 音质目前只保存，接真实播放（阶段 5）时传给取流。
- **主题**：`Theme.seedPresets`（8 个预设种子色），`Main.qml` 绑定 `fixedSeed`。
- **控件**：
  - 单选的 `ConnectedButtonGroup`／`StandardButtonGroup` 是一个 Tab 停留点，←／→ 切换（选中跟着焦点走），所以评论页的排序按钮也一样。
  - `ListItem` 的说明文字换行后会撑高。
  - `MenuItem` 加 `supportingText`（第二行说明，项高 60）。
- **页面**：
  - 通用组件都在 `ui/app/settings/`：`SettingsGroup`、`SettingRow`、`SwitchSetting`、`ChoiceSetting`、`MenuSetting`、`ActionSetting`、`SliderSetting`、`SeedSwatches`。
