# 听歌统计设计（已评审，2026-11-12）

状态：**已评审**（2026-11-12）。**维护者已定：§9 的 T1–T9 全部按建议。** 后端已完成（[本地收听历史 §6](../../api/local-listening-history.md)，提交 `30ab6ad`）；展示层、页面和真数据一起做（维护者 2026-11-12 定的顺序：后端 → 设计 → 接真数据）。

听歌统计是**这台电脑上、Cirrus 自己播放过的歌**的看板。它回答三个问题，页面也按这三个问题分成三段：

| 问题 | 内容 |
| --- | --- |
| 听了多少？ | 这段时间的总时长、每天（月）的起伏、次数、歌曲数、歌手数、新歌数 |
| 听了什么？ | 歌曲、歌手、专辑排行 |
| 什么时候听、从哪里听？ | 一周七天 × 24 小时的节奏图、播放来源 |

它和网易云的"听歌排行"（[library.md §3.3](library.md)）是两样东西：那个是云端记录，包括手机和官方客户端，只有名次；这个只算本机，但有时长、时段和趋势。两个页面互相有链接，数据不合并。

## 1. 后端给什么

一次查询 `ListeningStateService::stats(查询)` 返回一个范围内的全部数据：

| 数据 | 字段 | 说明 |
| --- | --- | --- |
| 汇总 | 总时长、播放次数、歌曲数、歌手数、专辑数、新歌数、有记录的天数 | 新歌：第一次计次落在这个范围里的歌 |
| 趋势 | 按日／周／月的时长和次数 | 只有有记录的时段，空的要界面自己补零 |
| 时段 | 24 小时、周一到周日各自的时长和次数 | 两个一维分布；§5 的节奏图要的 7×24 交叉表还没有（T3） |
| 排行 | 歌曲、歌手、专辑、来源，各 1–100 条，按次数或按时长 | 歌曲带歌名、歌手、专辑、封面、时长的快照；信息还没补上的歌只有 ID |
| 连续天数 | 当前、最长、最长那次的结束日、最近一天 | **全部时间**，不随范围变 |
| 其他 | 第一条记录的时间、范围内还缺信息的歌曲数 | |

- **计次**：不是试听片段且听满 30 秒算一次；歌本身不足 30 秒的，听完或听了九成也算。**时长**包括所有播放。
- 每个账号各自统计，未登录（游客）也有自己的一份。时间按本机时区，周从周一开始。
- 在本机数据库里聚合，一次返回，不分页。

### 2.1 页头

- 标题"听歌统计"（headlineMedium，与音乐库、搜索页同级）。副标题一行（bodyMedium、OnSurfaceVariant）："这台电脑上的播放记录 · 2026年11月8日起"（日期是第一条记录的日期）；游客写"游客的播放记录 · …"。
- **连续天数**在页头右侧，是一块小卡片（tertiaryContainer，large 圆角）：火焰图标、"连续 4 天"（titleMedium）、"最长 12 天"（bodySmall）。它是全部时间的数字，不随下面的范围变，所以放在范围选择的上方。今天和昨天都没听时写"最长连续 12 天"，一次都没有时不显示。

### 2.2 范围

一行，管它下面的所有内容：

- `ConnectedButtonGroup`：**周、月、年、全部**。
- 旁边是 ‹ ›（图标按钮）和当前时段的名字："11月9日–15日""2026年11月""2026年"；"全部"没有这一段。‹ › 往前往后翻一个时段，翻不到未来，也翻不到第一条记录之前。不在当前时段时出现"回到本周／本月／今年"（Text 按钮）。
- 键盘：范围按钮组是一个 Tab 停靠点，←／→ 切换（和设置页的按钮组一样）。Alt+←／→ 已经是后退／前进，所以翻时段用 `[` 和 `]`（焦点不在输入框时），列进设置页的快捷键清单。
- 记住上次选的范围种类（周／月／年／全部），不记翻到的时段：再打开总是当前时段。

范围决定趋势图的粒度：

| 范围 | 趋势图的柱子 | 横轴标注 |
| --- | --- | --- |
| 周 | 7 根，每天一根 | 一 二 … 日 |
| 月 | 28–31 根，每天一根 | 1、8、15、22、29 |
| 年 | 12 根，每月一根 | 1月 … 12月 |
| 全部 | 每月一根；超过 36 个月改成每年一根 | 每年 1 月的位置标年份 |

### 2.3 主卡片：听了多少

一块 primaryContainer 的卡片（extraLarge 圆角，与首页"今日"、音乐库"我喜欢的音乐"同一家族），左边数字，右边趋势图。

- 第一行"本周听了"（titleMedium；翻到别的时段时是"11月2日–8日听了"）。
- **总时长**是全页唯一的大字：数字用 displayLarge（57 px），"小时""分"用 titleLarge，写法是"6 小时 12 分"；不足一小时"48 分钟"，满 100 小时只写小时。用比例数字，不用等宽数字。
- **与上一时段比**："↑ 比上周同期多 40 分钟"／"↓ 比上月同期少 2 小时"（bodyMedium，箭头图标）。时段还没过完时只和上一时段的同一段比（周四就比上周一到周四），过完的时段比整段。用普通文字色：多听少听没有好坏，不用状态色。上一时段没有记录、或范围是"全部"时不显示。（需要再查一次上一时段，T4。）
- **趋势图**（柱状图）：
  - 柱子最宽 24 px，顶端 4 px 圆角、底部平，柱间至少留 2 px；颜色 `primary`。没有记录的日子不画柱子；还没到的日子在基线上画一个小点（`onPrimaryContainer` 38%）。
  - 一到两条横向细线（1 px 实线）带刻度，取整的数："1 小时""2 小时"或"30 分钟"；最高的那根柱子顶上直接标数值。别的柱子不标，靠悬停。
  - 鼠标移到某一列（整列都算，不只是柱子本身）或键盘选中时，柱子叠状态层，弹出提示："周三 · **1 小时 48 分** · 14 次"。
  - "年""全部"里的柱子是月份，可以点：点了切到那个月（Enter 相同，鼠标是手形）。按天的柱子不能点，鼠标不变。
  - 切换范围时柱子的高度用弹簧过渡（`defaultSpatial`），不整块重画；减少动态效果时直接到位。

### 2.4 四个数字

主卡片下面一行四块小卡片（surfaceContainerLow，large 圆角）：**次播放、首歌、位歌手、首新歌**。数字 headlineMedium，说明 bodyMedium、OnSurfaceVariant。不带对比，不带小图：这一行只是把数字摆出来。

### 2.5 听得最多

- 段标题"听得最多"（titleLarge）右边是 `ConnectedButtonGroup`：**按次数、按时长**，三个排行一起变；记住选择。
- **歌曲** 10 行：名次、封面（40 px）、歌名和歌手、横条、数值。
  - 横条是 8 px 高的 `primary` 细条，长度相对第一名；数值在右边（labelLarge，等宽数字）："12 次"或"1 小时 12 分"。窄的时候横条落到歌名下面。
  - 行为和别处的歌曲列表一样（用 `SongList`，尾部换成横条和数值）：双击或 Enter 从这一首开始播放这个排行，右键是歌曲菜单，正在播放的行高亮。
  - "查看全部"打开排行的完整页：歌单页的版式（`SongCollectionPage`），图标块、"播放全部"、最多 100 首，范围和排序跟着看板走，表格多一列次数或时长。
  - 信息还没补上的歌显示"未知歌曲"，灰色，不能播放；后台补上后自动换成真的。
- **歌手**、**专辑**各 5 行，在歌曲右边（窄时在下面）：名次、名字（专辑带封面）、横条、数值。点一行打开歌手页／专辑页；只有名字、没有 ID 的歌手不能点。这一轮不做它们的完整页。
- 一首歌有几位歌手时，每位都算一次（和后端一致）。

### 2.6 什么时候听

**节奏图**是这个页面的标志：7 行（周一到周日）× 24 列（0 点到 23 点）的格子，颜色越深听得越多。

- 选"周"时，它就是这一周的时间表：周三晚上九点听了，那一格就亮；选"月""年""全部"时是这段时间加起来的习惯。比两张分开的柱状图多一层信息：能看出"工作日早上八点、周末深夜"这样的规律。
- 格子 20×20、间距 2、圆角 extraSmall（4）。颜色只用一个色相、五级：没有记录是 `surfaceContainerHighest`，有记录的四级是它和 `primary` 按 25%／50%／75%／100% 混合（`Theme.mix`），分级按这个范围里最多的那一格的四分之一、一半、四分之三来切。右下角图例"少 ▢▣▣■ 多"。
- 上边标 0、6、12、18、23，左边标一到日（labelSmall、OnSurfaceVariant）。
- 悬停或键盘选中一格：提示"周六 21–22 点 · **48 分钟** · 6 次"。
- 图下面一句话读出结论："最常在周六 21 点前后听"（最多的那一格；并列时取时间早的）。
- 需要后端加一个查询（T3）。不加的话退回两张小柱状图（24 小时、周一到周日），现有接口就够。

### 2.7 从哪里听

来源排行 5 行，在节奏图右边：名字、横条、数值。名字是歌单名／专辑名／歌手名，后面跟类别（"深夜通勤 · 歌单"）；没有名字的几类直接写"私人 FM""每日推荐""搜索""最近播放""听歌排行""其他"。歌单、专辑、歌手这几行可以点开。没有来源的播放（旧记录）不计入；一条来源都没有时整段不显示。

### 2.8 页脚

一行小字（bodySmall、OnSurfaceVariant）："听满 30 秒计一次播放，时长包含所有播放"。右边是"网易云听歌排行 ›"（Text 按钮，登录后才有），打开云端排行页；云端排行页的头部也加一个回到这里的入口。

## 3. 颜色

所有图形只用一个色相，没有"用颜色区分系列"的图，所以不需要另外的图表色板：

| 位置 | 容器 | 图形 | 文字 |
| --- | --- | --- | --- |
| 页面 | `surface` | | `onSurface`、`onSurfaceVariant` |
| 主卡片 | `primaryContainer` | 柱子 `primary`；网格线是 `onPrimaryContainer` 混 12% | `onPrimaryContainer`，次要文字 80% |
| 数字卡片 | `surfaceContainerLow` | | `onSurface`、`onSurfaceVariant` |
| 排行、来源 | 无（直接在页面上） | 横条 `primary` | 名字 `onSurface`，数值 `onSurfaceVariant` |
| 节奏图 | 无 | `surfaceContainerHighest` → `primary` 五级 | `onSurfaceVariant` |
| 连续天数 | `tertiaryContainer` | 图标 `tertiary` | `onTertiaryContainer` |

- 文字不用图形的颜色；数值、名字、刻度都是文字色。
- 分层靠色调，不用阴影（提示除外）。
- 亮色、暗色都取同名角色，不另配色。实现时在 gallery 里换几种主题色，亮暗各看一遍：节奏图最浅一级要能和空格子分开。

## 4. 键盘与读屏

- Tab 顺序：范围 → ‹ › → 趋势图 → 排序 → 歌曲列表 → 歌手 → 专辑 → 节奏图 → 来源 → 页脚链接。
- 趋势图和节奏图各是一个 Tab 停靠点，进去以后用方向键在柱子／格子之间移动（节奏图上下左右都能走），Home／End 到头尾，焦点环画在选中的那一个上，提示和悬停时一样。
- 提示里的内容只是方便，不是唯一的途径：每根柱子、每个格子都有读屏名称（"周三，1 小时 48 分，14 次"），排行本来就是文字列表。不另做"表格视图"。
- 所有能点的行、柱子都是手形光标（[controls.md §2](../controls.md)）。

## 5. 状态

| 情况 | 显示 |
| --- | --- |
| 一条记录都没有 | 整页一个空状态：图标、"还没有听歌记录"、"在这台电脑上播放的歌会出现在这里"，按钮"去发现" |
| 这个时段没有记录 | 页头和范围照常；主卡片写"这一周没有听歌"，趋势图只剩基线；下面各段不显示 |
| 第一次加载 | 骨架（主卡片、四个数字、列表行） |
| 换范围、翻时段 | 旧内容留在原地，新数据到了直接换，不闪骨架（查询在本机，等待很短） |
| 读取失败 | 页面错误状态和"重试" |
| 开着页面时又听完一首 | 当前时段的数字和图自动更新（记录写入后重新查一次，合并 2 秒内的多次） |
| 换账号、退出登录 | 重新加载成那个账号（或游客）的统计 |

## 6. 入口

- **侧边栏**"我的"下面加第三行"听歌统计"（柱状图图标），在"最近播放"下面。游客也有（"我喜欢的音乐""最近播放"游客没有，这一行有）。
- **音乐库**的歌曲清单卡片加第四张"听歌统计"（surfaceContainer，副标题是本周时长："本周 6 小时 12 分"）。
- 云端"听歌排行"页和这里互相链接（§2.8）。

## 7. 设置里的清除

设置 › 存储与隐私加一行"本地听歌记录"，说明"用于听歌统计"，右边"清除…"。点了先确认："清除这台电脑上的听歌记录？""听歌统计会清零，网易云上的记录不受影响"，按钮"取消""清除"。只清当前账号（或游客）的；后端已有（`ListeningSession::clearHistory()`，歌曲信息快照一起删）。

## 8. 不做的（这一轮）

- 自己选起止日期（周／月／年／全部加上翻页已经能到任何一段）。
