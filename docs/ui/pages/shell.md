# 外壳与侧边栏设计

状态：**第五版**（2026-10-31）：顶栏与内容面板（§0）。已定：侧边栏放歌单列表；搜索移到顶部（维护者让我选，选了顶部）；登录这类功能放在对话框里，不占用主内容区（维护者）。

第二版反馈后的修改：非自绘标题栏下进一次搜索页，标题栏那一行就再也不出现（行收起时整行被设为不可见，里面的搜索框也随之"不可见"，判断不出有内容）——改为只把高度收为 0；搜索入口改成真正的输入框（§3）；对话框改为桌面交互（§4）。整体要求：MD3E 外观、桌面操作逻辑，尽量都能只用键盘完成（维护者，2026-10-31）。

第一版反馈后的修改：搜索框上下太贴边 → 有应用内容时标题栏那一行高 56，搜索框上下各留 8；页面内容滚动时会盖住搜索框 → 页面栈裁剪到自己的区域。

外壳是所有页面共用的部分：导航栏（侧边栏）、标题栏那一行、页面栈和迷你播放条。窗口和标题栏模式见 [README §6.1](../README.md)，响应式分级见 §6.2，切换动效见 [motion-choreography.md §5](../motion-choreography.md)。

## 0. 框架：顶栏 + 侧边栏 + 内容面板（2026-10-31）

```text
┌───────────────┬───────────────────────────────────────────────────────────┐
│ ≡ (logo) Cirrus │ ← →  [🔍 搜索…   Ctrl+K]          [应用操作] ─ □ ✕ │ 顶栏
├───────────────┼─╭─────────────────────────────────────────────────────────╮
│ ⌂ 首页         │ │  内容面板（Surface，largeIncreased 圆角）                 │
│ ◎ 发现         │ │                                                         │
│ …              │ ╰─────────────────────────────────────────────────────────╯
│ (头像) 昵称  ⚙ │   迷你播放条                                              │
└───────────────┴───────────────────────────────────────────────────────────┘
```

- **顶栏就是标题栏那一行**，是应用界面的一部分，三种窗口装饰模式下都在。框架（顶栏、侧边栏、窗口底色）用 SurfaceContainer，页面在 Surface 的圆角面板里，四角用遮罩（`PanelCorner`），页面滚动不会画出面板；迷你播放条在面板下方。
- **顶栏从左到右**：侧边栏上方的区域与侧边栏同宽，放展开／收起按钮和应用名（logo 还没有，以后放在应用名前面），侧边栏展开时应用名淡入；然后是后退、前进、搜索框；最右是**应用操作区**（以后的全屏等），任何模式都显示，不能隐藏；窗口按钮在它之后，只在"应用绘制"模式出现，隐藏时应用操作区自然靠到最右。
- **顶栏空白处**拖动窗口、双击最大化、右键窗口菜单（"应用绘制"和"无"模式；系统模式由系统标题栏负责）。
- **窗口装饰**（设置项"窗口装饰"，启动参数 `--titlebar` 不变）：

  | 选项 | 窗口按钮、阴影、圆角 | 用在哪里 |
  | --- | --- | --- |
  | 应用绘制（默认，`custom`） | 应用画 | GNOME、KDE、Windows；macOS 保留红绿灯（顶栏左侧让出 72 px） |
  | 无（`hidden`） | 没有；保留顶栏、拖动和缩放边带 | 平铺窗口管理器（按 `XDG_CURRENT_DESKTOP` 判断，默认） |
  | 系统（`system`） | 系统标题栏，顶栏在它下面 | 出问题时的退路 |

- **窗口按钮**是超小号 `IconButton`（状态层、水波纹、按下变形与其他图标按钮一致），但符号不用图标字体（Material Symbols 的 close 只有 13.2／24 宽，最大化 18、还原 20，看起来大小不一），而是用 Material Symbols 的圆头线条（20 px 下约 1.75 px）在同一个方框里画。提示在按钮下方显示。
- **不用阴影分层**：框架、面板、迷你播放条之间只靠色调区分；迷你播放条没有底色和阴影，是框架的一部分。
- **后退／前进**在顶栏，页面不再各自放返回按钮。历史像浏览器：每打开一个页面（包括在侧边栏切换首页、发现、音乐库）都是一条记录，后退回到之前访问的那个页面（不是"上一级"），前进重新打开后退离开的页面，打开新页面时清空前进记录；点当前所在的目的地不新增记录。侧边栏的选中项随历史变化。Alt+←／Alt+→ 和鼠标侧键都可用。

## 1. 导航目的地

只有三个：**首页、发现、音乐库**。

- 搜索不再是目的地，挪到顶部（§3）。
- 设置挪到侧边栏底部（§2.3）。
- 私人 FM、每日推荐不进侧边栏：FM 是一种播放方式，不是页面；两者都在首页顶部。

## 2. 侧边栏

沿用 MD3E 导航栏（`NavigationRail`）：窗口 ≥ 1200 时展开、推开内容；更窄时收起，点菜单按钮浮在内容上方（带遮罩）。

### 2.1 展开（宽 272）

展开／收起按钮移到了顶栏左侧（§0），侧边栏从导航项开始。

```text
 ⌂  首页
 ◎  发现
 ▤  音乐库
 ───────────────
 我的
 ♡  我喜欢的音乐
 ◷  最近播放
 ───────────────
 创建的歌单  2    ⌃
 ▢  深夜通勤
 ▢  空歌单
 收藏的歌单  3    ⌃
 ▢  …              ← 这一段单独滚动
 ───────────────
 (头像) 昵称        ⚙
```

- **我的**：我喜欢的音乐、最近播放，分别打开"我喜欢的音乐"歌单和最近播放页（[library.md §4](library.md)）。
- **歌单**：账号创建的、收藏的两组，数据来自个人库（`myPlaylists`，用创建者区分）。每组标题带数量，点标题折叠或展开：行的高度随弹簧收放（`standardDefaultSpatial`），内容淡入淡出，箭头随之翻转；折叠后的行不可见，Tab 不会走到。每行是 28 px 小封面加歌单名，点开歌单详情；当前打开的歌单高亮（`secondaryContainer`）。
- 未登录时两组换成一句"登录后，你创建和收藏的歌单会显示在这里。"和"扫码登录"按钮。
- 这部分不是 MD3 导航栏的内容（MD3 的导航栏只放目的地），是桌面音乐客户端的惯例（网易云、Spotify、Apple Music 都这样）。所以保持 MD3 的观感：行高 44、整行胶囊形状态层、图标和文字与上面的导航项对齐（图标 x=36，文字 x=72）。它只在展开时出现，展开过半后淡入；收起时不显示。

### 2.2 收起（宽 96）

只有三个目的地；底部是设置图标和头像（上下排列）。要看歌单就点菜单按钮把侧边栏浮出来，或者去音乐库。

### 2.3 底部：账号和设置

- 登录后：头像 + 昵称，点开菜单（目前只有"退出登录"）。
- 未登录：账号图标 + "登录"，点击进入扫码登录页。
- 设置图标在右边（收起时在头像上方），点击打开设置页（压栈，可返回）。
- 展开和收起之间，头像、名字、设置图标的位置随导航栏的展开进度插值，不跳。

## 3. 搜索

顶栏放全应用唯一的搜索框（`SearchField`，40 px 高，在前进按钮右边，最宽 400），像浏览器地址栏一样工作：

- 下拉列表每次打开都从搜索框下沿展开并淡入，关闭时淡出；条数变化时高度用弹簧过渡（`standardFastSpatial`），不跳变。
- Ctrl+K 聚焦并全选（Ctrl+F 也是，除非当前页面有自己的页内查找，例如歌单页）；空着时下拉列表显示热门搜索，输入时显示搜索建议。输入第一个字就进入搜索页（压栈），键盘焦点留在搜索框里。
- ↑／↓ 在列表里选一行，Enter 搜索选中的那行（没选就搜索输入的文字），列表收起；也可以用鼠标点。
- Esc 依次是：收起列表 → 清空文字 → 把焦点交还给页面。
- 点击搜索框和列表以外的地方收起列表；再点搜索框、输入或按 ↓ 重新打开。
- 搜索页只显示热门搜索与结果，没有自己的搜索框；离开搜索页时清空搜索框，回到搜索页时显示它的搜索词。搜索框与搜索页共用外壳里的一个 `SearchModel`。
- 页面栈只在键盘焦点原本就在页面里（或无焦点）时把焦点交给新页面，所以在搜索框里打字进入搜索页不会丢焦点。

选顶部而不是导航目的地的理由：搜索是随时要用的动作，不是一个"地方"；放在顶部，任何页面都能一步进入。

## 4. 对话框

桌面交互（[controls.md §8c](../controls.md)）：标题行带关闭按钮，点击外面不关闭；Esc 取消，Enter 点击有焦点的按钮、否则执行默认按钮；Tab 只在对话框里循环；关闭后焦点回到打开前的位置。

不需要成为一个"地方"的功能放在对话框（`Dialog`，[controls.md §8c](../controls.md)）里，盖在当前页面上，关掉就回到原处，不进页面栈。目前是**扫码登录**（`LoginDialog`）：侧边栏底部的"登录"、侧边栏和首页的"扫码登录"都打开它；打开时开始扫码登录，关闭时取消未完成的登录，登录成功后自动关闭。以后的确认（退出登录、删除歌单）、新建歌单、添加到歌单等也照此处理。

## 5. 已知问题

- 窗口很矮时（接近最小高度 360），收起的侧边栏底部的设置和头像会压到导航项上。
- "我喜欢的音乐""最近播放"在打开对应页面时不高亮（"我喜欢的音乐"作为歌单在"创建的歌单"里高亮）。
- 网易云的"我喜欢的音乐"其实是一个歌单；接入真实后端时，这一项可能改为直接打开那个歌单。

## 7. 关闭、托盘与后台播放（2026-11-01）

依据 [Linux 集成 §4、§7](../../10-linux-integration.md)，维护者决定（UQ-10）：

- **托盘图标**：`QSystemTrayIcon`，CMake 选项 `CIRRUS_UI_TRAY`（默认开，链接 Qt Widgets、改用 `QApplication`；关掉时保留 `QGuiApplication`，关闭窗口总是退出）。Linux 上 Qt 走 StatusNotifierItem（KDE、带扩展的 GNOME、Waybar 等），没有时退到 XEmbed。菜单：当前歌曲（灰）、播放／暂停、上一首、下一首、显示主窗口、退出 Cirrus。单击显示窗口，中键播放／暂停。图标是占位（`ui/app/icons/cirrus-music.svg`，UQ-06 定应用身份时替换），同时作窗口图标。
- **关闭主窗口**：第一次关闭弹出"关闭主窗口"对话框（`CloseDialog`，2026-11-01 按维护者要求改为单选项）：最小化到托盘，继续播放（默认）／退出 Cirrus，"不再询问"默认勾选，按钮为取消／确定；Esc、取消或关闭按钮不关窗口。设置 › 窗口 › "关闭主窗口时"：每次询问／最小化到托盘／退出。
- **没有托盘时**（例如没装扩展的 GNOME）：维护者决定照样按用户的选择在后台播放，不改成退出。文案换成"在后台继续播放"／"后台播放"，并说明回到窗口的办法：再次打开 Cirrus（单实例激活）；退出用 Ctrl+Q（`StandardKey.Quit`，全应用快捷键）。每次关闭前重新检查托盘（面板可能比应用晚启动），出现后补上托盘图标。
- **退出**：托盘菜单的退出、`Qt.quit()`、会话结束都先置 `Desktop.quitting`，此时关闭窗口不会被改成隐藏。
- **单实例**：`QLockFile` + `QLocalServer`，放在 `$XDG_RUNTIME_DIR/CirrusMusic/`（0700）。再次启动只发一行 `activate [令牌]`（≤ 512 字节，令牌按字符白名单校验），已运行的实例显示并激活窗口后，新进程退出。Wayland 下转交启动器给的 `XDG_ACTIVATION_TOKEN`，显示窗口时由 Qt 使用。锁的持有进程已不在时视为过期锁；持有者不应答时照常启动，不会卡住。
- **隐藏时释放显卡**：窗口 `persistentGraphics`、`persistentSceneGraph` 设为 false，隐藏到托盘时释放图形设备和场景图，后台长时间播放时独显可以休眠；显示时重建。
- **独立显卡（Linux）**：混合显卡（核显接屏幕、另有 nvidia／nouveau／amdgpu／radeon 驱动的显卡且不是 `boot_vga`）时默认用独显：NVIDIA 专有驱动设 prime-run 的三个变量（`__NV_PRIME_RENDER_OFFLOAD`、`__GLX_VENDOR_LIBRARY_NAME`、`__VK_LAYER_NV_optimus`），Mesa 设 `DRI_PRIME=pci-…`。用户已设其中任一变量，或 `CIRRUS_GPU=default` 时不动。设置 › 窗口 › "使用独立显卡"（只在混合显卡机器上显示），重启后生效。Windows 用系统的按应用图形设置，macOS 由系统选择，都不处理。
- 媒体键、MPRIS、系统媒体控件属于后端 B-031，不在 UI 实现。

代码：`ui/app/desktop.*`（QML 单例 `Desktop`）、`tray.*`、`single_instance.*`、`gpu_preference.*`、`app_icon.h`、`CloseDialog.qml`；`Main.qml` 的 `onClosing`；`AppSettings` 加 `closeAction`、`preferDiscreteGpu`。

未验证：真实托盘（离屏平台没有托盘）、Wayland 激活令牌、独显实际是否用上和休眠（可看 `/sys/bus/pci/devices/0000:01:00.0/power/runtime_status`，`nvidia-smi` 里应有本进程）、Windows／macOS。
