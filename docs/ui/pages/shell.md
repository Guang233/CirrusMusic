# 外壳与侧边栏设计

状态：**第一版已实现，等待维护者看效果**（2026-10-31）。已定：侧边栏放歌单列表；搜索移到顶部（维护者让我选，选了顶部）。

外壳是所有页面共用的部分：导航栏（侧边栏）、标题栏那一行、页面栈和迷你播放条。窗口和标题栏模式见 [README §6.1](../README.md)，响应式分级见 §6.2，切换动效见 [motion-choreography.md §5](../motion-choreography.md)。

## 1. 导航目的地

只有三个：**首页、发现、音乐库**。

- 搜索不再是目的地，挪到顶部（§3）。
- 设置挪到侧边栏底部（§2.3）。
- 私人 FM、每日推荐不进侧边栏：FM 是一种播放方式，不是页面；两者都在首页顶部。

## 2. 侧边栏

沿用 MD3E 导航栏（`NavigationRail`）：窗口 ≥ 1200 时展开、推开内容；更窄时收起，点菜单按钮浮在内容上方（带遮罩）。

### 2.1 展开（宽 272）

```text
 [≡]
 ⌂  首页
 ◎  发现
 ▤  音乐库
 ───────────────
 我的
 ♡  我喜欢的音乐
 ◷  最近播放
 ───────────────
 创建的歌单  2    ⌃
 ▢  深夜通勤
 ▢  空歌单
 收藏的歌单  3    ⌃
 ▢  …              ← 这一段单独滚动
 ───────────────
 (头像) 昵称        ⚙
```

- **我的**：我喜欢的音乐、最近播放，分别打开音乐库的"喜欢""最近播放"标签。
- **歌单**：账号创建的、收藏的两组，数据来自个人库（`myPlaylists`，用创建者区分）。每组标题带数量，点标题折叠或展开。每行是 28 px 小封面加歌单名，点开歌单详情；当前打开的歌单高亮（`secondaryContainer`）。
- 未登录时两组换成一句"登录后，你创建和收藏的歌单会显示在这里。"和"扫码登录"按钮。
- 这部分不是 MD3 导航栏的内容（MD3 的导航栏只放目的地），是桌面音乐客户端的惯例（网易云、Spotify、Apple Music 都这样）。所以保持 MD3 的观感：行高 44、整行胶囊形状态层、图标和文字与上面的导航项对齐（图标 x=36，文字 x=72）。它只在展开时出现，展开过半后淡入；收起时不显示。

### 2.2 收起（宽 96）

只有三个目的地；底部是设置图标和头像（上下排列）。要看歌单就点菜单按钮把侧边栏浮出来，或者去音乐库。

### 2.3 底部：账号和设置

- 登录后：头像 + 昵称，点开菜单（目前只有"退出登录"）。
- 未登录：账号图标 + "登录"，点击进入扫码登录页。
- 设置图标在右边（收起时在头像上方），点击打开设置页（压栈，可返回）。
- 展开和收起之间，头像、名字、设置图标的位置随导航栏的展开进度插值，不跳。

## 3. 搜索

标题栏那一行放一个 40 px 高的搜索框，左边与页面内容对齐，最宽 360。它只是入口：点击或按 Ctrl+K／Ctrl+F 打开搜索页（压栈），输入在搜索页自己的搜索框里进行；在搜索页时顶部这个框隐藏，避免出现两个。

三种标题栏模式下都在：自绘模式与窗口标题、窗口按钮同一行；系统和隐藏模式下这一行只剩搜索框（[README §6.1](../README.md) 的"标题栏那一行"规则）。

选顶部而不是导航目的地的理由：搜索是随时要用的动作，不是一个"地方"；放在顶部，任何页面都能一步进入。

## 4. 已知问题

- 窗口很矮时（接近最小高度 360），收起的侧边栏底部的设置和头像会压到导航项上。
- "我喜欢的音乐""最近播放"在打开对应音乐库标签时不高亮。
- 网易云的"我喜欢的音乐"其实是一个歌单；接入真实后端时，这一项可能改为直接打开那个歌单。
