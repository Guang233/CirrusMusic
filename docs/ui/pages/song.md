# 歌曲页设计（已评审，2026-11-13；已实现）

状态：**已评审**（2026-11-13，S1–S6 按建议），**已实现**（同日，§9）。维护者 2026-11-13 定：歌曲百科和相似推荐做成一个歌曲页（不是播放页菜单里的两个对话框）；不做 gallery 的假数据（gallery 只展示设计因子）。

歌曲页就是"一首歌自己的页面"：这首歌是什么（头部、百科），以及从它出发还能听什么（相似歌曲、相似歌单）。版式和专辑页同一个家族（[album-daily.md §1](album-daily.md)）：封面在左的头部、操作行，下面是一列段落，整页一起滚动，没有标签页（内容不多，标签页反而要多点一下）。

## 1. 后端给什么

都已有，界面没接（`BackendFacade::songWikiText`、`songWiki`（旧摘要）、`discover`）：

| 内容 | 接口 | 给的东西 | 实测 |
| --- | --- | --- | --- |
| 歌曲本身 | 歌曲详情（已在用，`songDetails`） | 标题、别名、译名、歌手、专辑、封面、时长、发行时间 | 已用 |
| 百科：标签卡片 | `SongWikiSummary`（`/api/song/play/about/block/page`） | 几张卡片：曲风、推荐标签、语种、BPM，每张一个标题和几个值（都是网易云给的显示文字） | 没测过 |
| 百科：资料 | `SongWikiText`（`/api/link/page/parent/relation/construct/info`） | 两节："歌曲信息""基础信息"，每节若干行"标题＋内容"（内容是一段文字或几个短文本）。其余块（奖项、影视综艺、曲谱、更多版本、首听……）后端不解析 | 2026-10-08 游客 2 次，结构对得上；内容身份"未独立验证"（后端文档的说法：靠歌名和专辑对上，没有别的证据） |
| 相似歌曲 | `SimilarSongs`（`/api/v1/discovery/simiSong`） | 一批歌（后端一次最多收 100；分页不可靠，只读一批） | 游客 1 次，请求 2 首给了 5 首 |
| 相似歌单 | `SimilarPlaylists`（`/api/discovery/simiPlaylist`，种子是歌曲） | 一批歌单（标题、封面、创建者、播放量） | **没测过** |

百科有两个来源，是因为后端先后接了两个接口，各给一部分：旧摘要给结构化的标签（适合做成标签块），新接口给资料行。两个都读，各自没有就不显示。

## 2. 版式

```
┌────────┐  歌曲                                        ← labelLarge，primary
│        │  海风写给你的信                               ← headlineLarge；别名、译名在下一行小字
│  封面  │  雾港乐队 / Lumen Avenue                     ← 每位歌手可点（链接样式）
│  200   │  落日航线 · 2024年5月1日发行 · 3:41           ← 专辑可点；缺哪项省哪项
└────────┘
[▶ 播放] [♡] [评论 128] [⋯]                              ← ⋯：下一首播放、加到播放队列、收藏到歌单…、复制歌曲信息

百科                                                     ← titleLarge
 曲风  华语流行  独立流行      语种  国语      BPM  92    ← 标签块（旧摘要的卡片）
 ┌ 歌曲信息 ──────────────────────────────────────┐
 │ 作词      某某                                   │     ← 资料行：左标题（onSurfaceVariant），右内容
 │ 作曲      某某                                   │
 │ 编曲      某某 / 某某                            │
 └──────────────────────────────────────────────┘
 ┌ 基础信息 ──────────────────────────────────────┐
 │ 发行时间  2024-05-01                             │
 │ ……                                              │
 └──────────────────────────────────────────────┘
 资料来自网易云音乐                                       ← bodySmall，onSurfaceVariant

相似歌曲                                    [▶ 播放全部]
 1  ▢ 清晨六点的森林广播        林间信号        4:43       ← SongList，最多 10 行
 …
                         展开全部 32 首 ⌄                ← 超过 10 首时

相似歌单                                                  ← 一行卡片（与首页、音乐库同一种卡片）
 ▢ ▢ ▢ ▢ ▢ ▢
```

- **头部**
  - 封面 200（窄窗口 140），与专辑页相同；点封面不做什么（没有更大的图要看）。
  - 类型行写"歌曲"，与专辑页的"专辑"同一位置、同一样式。
  - 歌手：多位用" / "分隔，各自可点，进歌手页。专辑名可点，进专辑页。
  - 第三行：专辑 · 发行时间 · 时长，缺哪项省哪项。
- **操作行**
  - 播放（Filled）：从这首歌开始播放，替换播放队列为这一首（与专辑页"播放全部"同一类操作；想插队用"下一首播放"）。
  - 喜欢（图标按钮，红心，和列表里的红心同一个状态）。
  - 评论（有数字写数字，进评论页）。
  - 更多（⋯）：下一首播放、加到播放队列、收藏到歌单…、复制歌曲信息——歌曲行菜单的条目去掉"查看评论""查看专辑""查看歌手"（头部已经有），加上播放页菜单里的"复制歌曲信息"。
- **百科**
  - 标签块：每张卡片一组——标题（labelLarge，onSurfaceVariant）加几个值（Assist 样式的小块，不可点：网易云的标签没有我们能去的页面）。卡片之间横向排、放不下换行。
  - 资料：每节一个 surfaceContainerLow 的块（large 圆角），节名作块标题（titleSmall），里面是两列的行：左列标题定宽（取这节最长标题，最多 120 px），右列内容，长内容换行。一行有多个短文本时用" / "连起来。
  - 文字都是纯文本、可选择复制（`SelectableText`，[controls.md §8e](../controls.md)：只读正文可选）；里面像链接的东西也只是文字，不做成链接（后端文档的要求）。
  - 段尾一行"资料来自网易云音乐"：后端要求不宣称是完整、确认过的百科，这行把来源说清楚，不另写解释（S3）。
  - 两个来源都没有内容：整段不显示。只有一个来源有：只显示那部分。
- **相似歌曲**
  - `SongList`（带封面），先显示 10 行；超过 10 首时下面一个"展开全部 N 首"按钮，在原地展开（不另开页，数量不多）。
  - "播放全部"放在段标题右边；双击一行从这一行播放这批歌。来源记为"歌曲"（`Playback.FromSong`，id 是这首歌），听歌统计的来源里算"其他"。
  - 行菜单与其他列表相同。
- **相似歌单**
  - 一行歌单卡片（与首页"推荐歌单"同一种），放不下的部分不显示（不横向滚动，不分页）；点卡片进歌单页。
- **段落的顺序**：百科在前，因为它回答"这首歌是什么"，是进这一页的主要目的；相似推荐在后（S4）。

## 3. 入口

- **歌曲行菜单**（所有歌曲列表、表格）：加"歌曲详情"，放在"查看评论"上面（S2）。
- **播放页"更多"菜单**：加"歌曲详情"，先退出播放页再打开（播放页去别的页面一律如此，[player.md](player.md)）。
- **播放页的歌名**：可点，进歌曲页（现在只有歌手名可点）。
- **评论页**：歌曲评论页头部的歌名可点，进歌曲页。
- 迷你播放条的歌名点了是打开播放页，不改。

## 4. 状态

| 情况 | 显示 |
| --- | --- |
| 第一次进入 | 头部有就先显示（列表里点进来时已经有标题、歌手、封面）；百科、相似歌曲、相似歌单各自显示骨架，各自到了各自替换 |
| 某一段读取失败 | 那一段写"没能加载"和"重试"，不影响其他段 |
| 某一段为空 | 那一段整个不显示 |
| 歌曲本身读取失败 | 整页错误状态和"重试"（没有标题就没有这一页） |
| 无版权的歌 | 头部照常，"播放"不可用（与列表里灰色的行相同）；百科和相似推荐照常显示 |
| 游客 | 都读（相似歌曲游客实测能读；百科游客实测能读；相似歌单待实测，读不了就当空） |
| 换账号 | 重新读（相似推荐可能因人而异） |

## 5. 键盘与读屏

- Tab 顺序：头部的歌手、专辑链接 → 操作行 → 百科（可选文本不进 Tab）→ 相似歌曲的"播放全部"、列表（一个 Tab 停留点）、"展开" → 相似歌单卡片。
- 歌曲页没有页内快捷键；Alt+←／→ 返回、前进照常。
- 标签块、资料行有读屏名称（"作词：某某"）。

## 6. 不做的（这一轮）

- 百科的其余块：奖项、影视综艺、曲谱、MV、精彩评论、更多版本、首听、相关播客。后端没接，结构没有补证；要做先补证（S5）。
- 心动模式（从一首歌持续推荐），后端没有。
- 歌词全文：播放页已有。
- 相似歌手：在歌手页（已有）。

## 7. 实现步骤

1. **实测**（游客，几次，间隔开）：旧摘要、相似歌单从没测过；相似歌曲、新百科再各看一两首。确认字段和"空"的样子，回写 §1。
2. **展示层**：`CatalogSource` 加 `songWiki(key)`（两个百科接口合成一个结果：标签卡片＋资料节）、`similarSongs(key)`、`similarPlaylists(key)`；`BackendCatalog` 实现；`SongPageModel`（头部用歌曲详情）和三个子模型。不做假实现。
3. **页面**：`SongPage.qml`、`AppShell.openSong(key)`；资料行、标签块如果别处也用得上，放进 `Cirrus.Components`。
4. **入口**：行菜单、播放页菜单和歌名、评论页歌名。
5. **验证**：真实后端下截图（测试数据目录、临时钩子）；构建、qmllint；文档回写。

## 9. 实现记录（2026-11-13）

- **实测**（游客，两首歌，每首 5 次读取：详情、两个百科、两个相似）：都是 HTTP 200、业务码 200。
  - 相似歌曲：两首都是 5 首（请求 50）。相似歌单：两首都是 3 个（第一次实测）。
  - 旧百科摘要：卡片是"曲风""语种""BPM"，各一个值。
  - 新百科：节名是"创作信息""基本信息"（不是后端文档猜的"歌曲信息"），行如"作曲""发行时间""发行版本""曲风""BPM"；一位作者一行。**后端原来把这个响应整个拒掉**：`blockInfo.desc` 和行上的 `wikiSubMetaVos` 是 `null`，旧规则"出现的 null 一律拒绝"。改为 null 等同缺失、没有内容的行跳过（`b0e5f13`，[song-wiki-text-subset.md](../../api/song-wiki-text-subset.md) 的修订段）。
- **展示层**：`CatalogSource::songWiki(song)`（两个百科读取合成一个结果，一个失败只少那部分）、`similarSongs`、`similarPlaylists`；`SongPageModel` 和三个子模型（`ui/presentation/song_page_model.*`）。没有假实现（假数据源里是返回空的桩，只为接口能编译）。
  - 合并时整理：相邻同名的行合成一行（"作曲：A / B"）；和标签卡片说的一样的行（曲风、BPM）去掉；空节去掉。
  - 相似歌曲去掉这首歌本身和重复。`SongInfo` 加了 `publishedAtMs`（头部的发行日期）。
- **页面**：`ui/app/SongPage.qml`、`AppShell.openSong(key)`。各段用首页的 `HomeSection`（骨架、失败一行加重试、空时隐藏），它加了 `trailing`（相似歌曲的"播放全部"）。`SongList` 加了 `rowLimit` 和 `heightFor()`（先显示 10 行，第 10 行仍是分段列表的圆角底）。所有资料节共用一个标签列宽，内容对齐。
- **入口**：`SongTable`、`SongList` 的行菜单"歌曲详情"（`songRequested`）；播放页"更多"菜单的第一项和可点的歌名（`SongHeader.songRequested`，先退出播放页）；歌曲评论页头部的歌名。
- **和设计的出入**：
  - 评论按钮不带数字（歌曲详情里没有评论数）。
  - "复制歌曲信息"直接复制"歌名 - 歌手 - 专辑"并提示，不开播放页那个带歌词的对话框（那个对话框绑定正在播放的歌）。
- **验证**：构建、qmllint、clang-format；`tst_song_wiki_text` 85 项、`songWikiTextThroughThread` 通过；临时钩子（`build/research-scripts/song-page-hook.patch`，已撤）下截了宽窗口和 760 宽的两首歌。登录后的相似推荐、无版权歌曲的样子没有看。
