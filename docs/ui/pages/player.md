**维护者已定**：P1–P12 按 §11。初稿之后的修改：

- 歌词粗细直接按字重设置。
- 亮色、暗色各有一套从封面取色的配色，不再始终深色。
- 文字、图标的颜色也从封面取：淡到几乎看不出取过色，明度参照 B 站暗色模式那种柔和的浅灰，不用纯白。

- 播放模式按网易云的习惯合并成一个按钮。
- 注音以假名为锚点对齐（§6）。

播放页是整个应用最重要的一页，风格接近 Apple Music（README §2.1）。维护者的要求：

- **沉浸感**：背景动态流光、有立体感的封面、自动隐藏控件、铺满整个窗口（包括顶栏）。
- **高度可自定义**，尤其是歌词。
- **日语音译以注音的样式写在汉字上方**。
- 滚动歌词和逐字歌词要单独设计。

和外壳的边界沿用 README §2.3：菜单、对话框、提示条用 MD3E 控件，套用从封面派生的配色（亮暗跟随播放页）；去歌手页、专辑页、评论页时先退出播放页。参考对象只取 Apple Music 的体验，AMLL、SPlayer 等是 AGPL 项目，代码一律不复制（[references.md §4](../references.md)）。

## 1. 结构与视图

播放页是盖在外壳上面的一层，打开时铺满整个窗口（§2.1）。内容分两个视图（P6，2026-11-07 起队列不再是视图，改为侧边面板，§8）：

| 视图 | 宽窗口（内容宽 ≥ 1000） | 窄窗口 |
| --- | --- | --- |
| 封面 | 封面居中放大，歌曲信息和控制区在封面下方 | 同左 |
| 歌词 | 左栏：封面、歌曲信息、控制区；右栏：歌词 | 顶部一行小封面和歌名，下面是歌词，控制区在底部 |

- 右下角的"歌词"开关切换两个视图（`L`）。"队列"（`Q`）和"显示设置"打开从右侧滑入的面板，同一时间最多开一个。
- 下次打开播放页时回到上次的视图。当前歌曲没有歌词时，歌词视图显示对应的状态（§5.7），不自动切回封面。

```text
│        ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━                                    │

│        [模式]   ⏮     ⏯     ⏭    ♡                                       │
│                                                                          │

```

- **左栏**：宽度占 40%，最宽 520。封面宽度等于左栏宽减去两侧边距，同时不超过窗口高度的 52%。
- **右栏**：歌词，默认左对齐（可改为居中，§9）。
- **歌曲信息**：
  - 歌名字号是 titleLarge 的放大版，歌手用次要色。点击歌手或专辑名时，先退出播放页再打开对应页面。
  - 右边是"更多"，菜单里有：评论、查看歌手、查看专辑、加入歌单、下一首播放、分享链接。评论的入口原来就留给了播放页，放在这里。
- **控制区**：播放模式、上一首、播放／暂停、下一首、喜欢。按钮都不带容器，按下时缩放；播放／暂停最大。
- **播放模式**：按网易云的习惯，一个按钮点击轮换四种模式，悬停时显示当前模式的名字。

  | 模式 | 对应的后端设置（order、repeat） |
  | --- | --- |
  | 列表循环 | Sequential、All |
  | 单曲循环 | 保持原来的 order，One |
  | 随机播放 | Shuffle、All |
  | 顺序播放（播完列表就停） | Sequential、Off |

  轮换顺序是列表循环 → 单曲循环 → 随机播放 → 顺序播放。外壳里显示播放模式的地方（迷你播放条以后要加的话）也用同一个按钮。
- **进度条**：平时细（4），悬停或拖动时变粗（8）。拖动期间只预览位置，松手才跳转（README §7.4）。填充跳到新位置（跳转、换歌）时像 MD3 进度条一样用弹簧过去，平时跟着时钟走。当前时间和右侧时间在进度条下方；右侧显示剩余时间或总时长（设置"右侧时间"），点一下右侧时间也能切换。
- **音量**：始终在页面最下面一行，靠右，和视图开关排在一起，不跟着控制区移动。
  - 平时只是一个图标按钮，图标随音量变化：`volume_off`、`volume_mute`、`volume_down`、`volume_up`。
  - 点击后在按钮上方弹出一条竖向的音量条（播放页语言：半透明底、内容色），可以拖动；按钮上滚动滚轮也能直接调节音量，不必打开音量条。
  - 音量条打开时，`↑`、`↓` 每次调 5%，`M` 静音或恢复，`Esc` 或点击别处关闭；音量条打开期间控件不自动隐藏。

## 2. 铺满窗口与自动隐藏

### 2.1 铺满窗口（P5）

- **窗口装饰为"应用绘制"**：
  - 播放页盖住顶栏，从窗口最上沿开始。
  - 窗口按钮浮在右上角，用内容色（§3.3），悬停时出现半透明的内容色底。颜色过渡沿用 motion-choreography §2.2。
  - 顶部 48 的空白处可以拖动窗口、双击最大化，和顶栏一样。
- **装饰为"无"**：没有窗口按钮，其余相同。
- **装饰为"系统"**：播放页从系统标题栏下面开始。
- **关闭播放页**：左上角的关闭按钮（`expand_more`）、`Esc`，或点击底部空白处（§2.3）。处在全屏时，第一次 `Esc` 先退出全屏。
- **真正的全屏**：
  - 右上角的 `⛶` 或 `F` 键把窗口切换成全屏（`showFullScreen`），再按一次回到原来的状态（最大化或普通窗口）。
  - 全屏时没有窗口按钮。
  - 关闭播放页时，如果全屏是从播放页切换的，一并退出全屏。

### 2.2 自动隐藏（P4）

播放中，鼠标不动、键盘也没有输入达到设定时间（默认 3 秒，§9）后，下面这些淡出（`slowEffects`）：

- 控制区（进度条、播放按钮），以及最下面一行（音量按钮、视图开关）。
- 顶部的关闭、全屏和窗口按钮。
- 鼠标指针（`Qt.BlankCursor`）。由盖在最上面的 `MouseArea` 设置：给元素设置或取消光标会立即生效，`HoverHandler` 的光标要等鼠标下一次移动才更新，而隐藏时鼠标正好是静止的。

留下的只有背景、封面、歌名和歌手、歌词。被隐藏的元素位置不变，只是变透明，其他内容不跟着挪。

- **重新显示**：鼠标移动或按任意键时淡入（`fastEffects`）。第一次按键只负责唤出控件，不执行动作，`Space` 除外：它照常播放或暂停。
- **隐藏期间的点击**：控件不接收点击，第一次点击只负责唤出控件。
- **不隐藏的情况**：
  - 已暂停。
  - 鼠标停在控制区上。
  - 键盘焦点在控制区里（`InputMode.keyboard`）。
  - 有菜单、对话框或面板打开。
  - 歌词处于浏览模式（§5.4）。
- **减少动态效果**：照常隐藏，但没有渐变，直接消失。
- **读屏软件**：始终能读到全部控件，隐藏只是视觉上的。

### 2.3 点击底部收起

最下面一行（高 64，迷你播放条原来的位置）的空白处可以点击，关闭播放页。打开时点迷你播放条，关闭时点同一个位置，两个方向对称。

- **范围**：只算空白处。音量、视图开关、底部控制区和进度条照常响应，在它们之间的缝隙里点击也不会关闭。
- **提示**：鼠标移到空白处时，底部浮现一层很淡的内容色渐变（8%），中间出现 `expand_more` 箭头（控制区在底部时不显示箭头），指针变成手形。不另外做首次引导。
- **不加开关**：
  - 误触的代价很小，再点一次迷你播放条就回来了。
  - 控件隐藏期间，第一次点击只唤出控件（§2.2），不会直接关闭。
  - 悬停提示本身就说明了这个区域能点。

## 3. 配色与背景（P1、P2）

### 3.1 亮暗两套

播放页默认跟随外观的明暗（`Theme.dark`），可以在设置里固定为"始终深色"或"始终浅色"（§9）。两套配色用同一次取色结果，只是色调范围不同：

| | 背景（流光的色点） | 内容色：主要 | 内容色：次要 |
| --- | --- | --- | --- |
| 暗色 | 色调 15–35，彩度 115% | 色调 85 | 色调 68 |
| 亮色 | 色调 66–86，彩度 115% | 色调 15 | 色调 32 |

- 内容色带着封面的平均色相（彩度 16／18），文字和图标看得出封面的色调。
- 两套都保证主要内容色在背景任意位置的对比度不低于 5:1，次要内容色不低于 3:1，不需要额外加遮罩。
  - 暗色：85 对 35 大约 5.1:1，68 对 35 大约 3.0:1。
  - 亮色：15 对 66 大约 5.8:1，32 对 66 大约 3.3:1。
- **黑白封面**（2026-11-10，维护者反馈"黑白为主的封面取到绿色"）：MD3 的打分偏向彩度高的颜色，一小块绿色（占比过 1%）或整体偏绿的灰（彩度 5–10，扫描、印刷、压缩带来的）都会被选成种子色，Tonal Spot 再把它拉成鲜明的绿色。现在取色时数一下彩度 ≥ 15 的像素占比，不到 10% 就算黑白封面（`CoverPalette::monochrome`）：种子色是封面平均色调的灰（于是用单色配色），流光的格子、纯色、阴影都去掉彩度，内容色为中性。外壳的封面主题色也一样。`tst_cover_palette`：黑白、2.4% 绿块、偏绿灰都判为黑白，四分之一红色和蓝橙两色不算。
- 2026-11-10 维护者反馈"背景不明显，白色太厚"：原来亮色是色调 82–94、彩度 70%，接近白色。改为 66–86、彩度 115%（暗色彩度也提到 115%），内容色跟着加深。离屏截图对照：灰调封面也能看出青色，鲜艳封面是明显的蓝紫。
- 具体数值在原型中用浅色封面、高饱和封面、黑白封面检查后回写本节。

### 3.2 动态流光

从封面取出几种颜色，形成几团很大、边缘柔和的色块，缓慢地漂移、旋转、交融，像有光在背后流动。

做法是**网格渐变**，自己写片段着色器（`ShaderEffect`，经 ShaderTools 编译）：

- **颜色来自封面本身**：
  - 把封面缩到 5×5，每个像素作为一个控制点的颜色。这样能保留封面颜色的空间分布：封面上方偏蓝，背景上方也偏蓝。
  - 每个像素按到各控制点距离的高斯权重，在线性光下混合 25 种颜色，过渡平滑、没有接缝（`ui/player/shaders/flow.frag`）。
  - 坐标先经过一层缓慢变化的低频扭曲，颜色之间的边界变成弯曲的形状，不会出现直边。
  - 控制点颜色转到 HCT，保留色相和彩度，色调压进 §3.1 的范围。
    - 按这张封面自己的色调跨度拉伸，而不是把 0–100 整体压缩，否则色调接近的封面只剩几级差别，看不出流动。
    - 跨度小于 35 时按 35 算，颜色平淡的封面不会被过度放大。
- **流动**：
  - 每个控制点沿各自的正弦曲线漂移（周期 20–40 秒，相位各不相同），幅度大约是网格间距的 60%。控制点分布比画面大 35%，旋转时角落也有颜色。
  - 整体大约 60 秒转一圈。速度可调（§9）。
- **防止色带**：流光按 1/4 尺寸渲染，放大到全尺寸时叠加一层 ±0.5/255 的交错梯度噪声抖动（`present.frag`，同时裁出圆角）。大面积渐变在 8 位色深下会出现色阶。
- **开销**：
  - 只有 25 个控制点，每帧只算一遍全屏片段，不用模糊。
  - 暂停播放后，流动在大约 2 秒内慢慢停下。
  - 窗口最小化、隐藏或播放页关闭时，完全停止。
- **切歌**：新旧控制点的颜色用同一个进度过渡（`slowEffects`，motion-choreography §4），位置不跳。

其他样式与退路：

| 样式 | 用途 |
| --- | --- |
| 流光（默认） | 如上 |
| 静态（2026-11-10） | 流光的颜色和形状，但不流动（设置值 3）。换歌时颜色照样过渡 |
| 模糊封面 | 封面放大成两层，一大一小反向缓慢旋转、小的那层绕圈漂移；在 1/4 尺寸上重度模糊（相当于全尺寸 256 的半径），再在 `present.frag` 里把每个像素的色调线性映射进 §3.1 的范围（色相不变，彩度按同一系数），不再盖 55% 的纯色（那层纯色让画面发白发灰，2026-11-10）。和流光一样播放时流动、暂停后停下 |
| 纯色 | 封面主色，暗色取色调 20，亮色取色调 90；适合不喜欢动态背景或机器较弱的用户 |

- **软件渲染**（没有着色器）：退回为由同一组 5×5 颜色生成的静态渐变（`Gradient`）。
- **减少动态效果**：流光静止，成为一帧不动的网格渐变。

### 3.3 内容色

文字、图标、进度条、音量条、焦点环、窗口按钮，都用从封面取的内容色。效果是用户看不出取过色，只觉得这些元素和画面融为一体。

- **明度**：参照 B 站暗色模式。截图里主要文字是 #CDCECF（色调约 82），次要文字是 #7A7F87（约 53）：柔和、不刺眼，而且次要文字明显更暗。
  - 暗色下的色调取 85 和 68，比截图稍亮，因为流光背景比 B 站的纯色背景亮，要保证对比度（§3.1）。
  - 当前行已唱的部分也用主要内容色，不用纯白。
- **色相**：取背景整体的主色相，即控制点按面积加权的平均色相，而不是封面里最鲜艳的颜色。这样内容色就像被背景的光染上的一样。
- **彩度**：很低。暗色 6–10，亮色 10–16，在原型中调到只有放在纯灰旁边比较才能看出差别的程度。封面接近黑白（彩度低于 5）时，直接用中性色。
- **分层**：
  - 主要：歌名、当前行、图标。
  - 次要：歌手、时间、翻译。
  - 再淡的层级（未唱的歌词、其他行、进度条底轨）：主要内容色降低不透明度（未唱 40%，底轨 25%）。不透明度会随背景流动自然变化，比固定色调更融入。
- **过渡**：切歌时，内容色和背景用同一个进度过渡。

## 4. 封面（P3）

目标是让封面像一张实物唱片封套：有厚度、会反光，不是贴在背景上的一张图。

| 效果 | 做法 |
| --- | --- |
| 投影 | 大而柔和，颜色取封面最暗的颜色再压暗，向下偏移。亮色模式下更浅、更散 |
| 暂停时缩小 | 播放时比例为 1，暂停时缩到 0.86，投影同时变小变淡，像封面落回了桌面。`defaultSpatial` 弹簧，带一点回弹 |
| 悬停倾斜 | 鼠标在封面上方时，封面朝鼠标方向倾斜，最多 6°（绕 X、Y 轴的 `Rotation` 自带透视）；鼠标离开后用弹簧回正 |
| 高光 | 倾斜时，一块很淡的白色径向渐变反向移动，像光从表面滑过，裁在封面圆角内 |
| 圆角 | `Theme.shape.medium`（12）。播放页不用 MD3E 的异形形状（README §2.3） |

- 投影是"层级不用阴影"原则的例外，只用于播放页的封面（维护者已同意）。
- 减少动态效果：不倾斜，暂停时不缩放，只保留投影。

## 5. 歌词视图

### 5.1 每一行的组成

```text
 rokuji  no kane ga na ru
 [六時]  [の][鐘][が][鳴][る]          ← 注音（§6，对齐成功时；「六時」是一串汉字，整组注音）
  六時の鐘が鳴る                      ← 原文：逐字填充
  六点的钟声响起                      ← 翻译：原文的 60%，次要内容色
```

- **顺序**：注音、原文、翻译。对不齐的音译另起一行，放在原文和翻译之间，字号是原文的 60%。
- **字号与字重**：
  - 默认左对齐，可以居中或靠右。字号直接设置，默认 40（§9）。
  - 字重可以设置，范围 100–900，默认 700（§9）。字体通过 `Fonts.fontOf(family, weight, size)` 取（歌词可以有自己的字体，`family` 为空时同 `Fonts.font`），不直接设 `font.weight`（README §4.2）。
  - 翻译用同一个字重，只是字号更小。
- **间距**：行与行之间的空白默认是原文字号的 0.9 倍，可以调（§9）。同一行内各部分靠得更近，看起来是一个整体。

### 5.2 滚动（P7）

- **当前行的位置**：在歌词区高度 30% 处（可改为居中）。已唱过的行留在上方，下方能看到接下来的四五行。
- **瀑布式跟进**：换行时，从当前行开始，每行比上一行晚大约 35 毫秒起步，各自用弹簧（`defaultSpatial`）滑到新位置，整体像水流一样依次跟上。
- **按距离淡化**：
  - 当前行：不透明度 1，无模糊，比例 1。
  - 其他行：不透明度 0.4，比例 0.96（以行首为原点，不会左右晃动）。
  - 模糊：离当前行每远一行加 1.2，最多 5；只作用于可见的行，可以整体关闭（§9）。
  - 这些变化都用 `defaultEffects` 过渡。
- **布局**：不用 `ListView`，所有行用 `Repeater` 生成。每行的纵坐标由前面各行的高度累加得到；可见区域外的行不模糊、不跑弹簧。一首歌通常不超过 150 行，开销不大，也方便控制每行的延迟。

### 5.3 当前行的高亮

- **逐字歌词**（`timing = Words`）：
  - **填充**：每个字从左到右"灌满"。已唱的部分是主要内容色，未唱的部分是主要内容色的 40%，两者之间是一段大约半个字宽的柔和过渡。进度由 `PlaybackClock` 逐帧计算，不会一跳一跳。
  - **上浮**：唱到的字向上浮起大约字号的 4%，用弹簧过渡。等整行不再是当前行时，再一起落回。
  - **长音**：一个字持续 1 秒以上、而且字数不多时，这个字慢慢放大到 1.08 倍，周围出现一圈柔和的光晕，唱完后回落。光晕是内容色：暗色下是亮晕，亮色下是一层很淡的同色晕。可以关闭（§9）。
- **逐行歌词**（`timing = Lines`）：整行在 `defaultEffects` 内从 40% 亮到 100%，不做填充。
- **纯文本歌词**（`PlainText`）：不滚动、不高亮，可以自由翻看，顶部提示"歌词没有时间信息"。
- **同时有多行**（`activeLines` 有多个，例如和声、重叠）：每行各自高亮，滚动以最早开始的一行为准。
- **一行唱完而下一行还没开始**：保持高亮，直到下一行开始。间隔较长时显示间奏（§5.5）。

### 5.4 浏览模式

- **进入**：用滚轮或拖动翻看歌词时进入。停止跟随，所有行去掉模糊，不透明度统一升到 0.6。
- **跳转**：悬停的行出现一块半透明的圆角底，点击就跳到这一行的开头并退出浏览模式。拖动时不触发跳转。
- **退出**：停止操作 3 秒后自动回到跟随模式，滚回当前行。按 `Esc` 立即回到当前行，再按一次才关闭播放页。
- **键盘**：`Tab` 进入歌词区后，`↑`、`↓` 逐行移动焦点（相当于浏览模式），`Enter` 跳到焦点所在的行。歌词区只占一个 Tab 停留点，和其他列表一致。

### 5.5 间奏

前一行结束到下一行开始之间超过 4 秒时，在下一行的位置上方显示三个圆点。歌曲开头、歌词里的空行也算。

- 三个点在间奏期间依次从 40% 亮到 100%，表示还剩多少时间；同时整体缓慢呼吸（比例 1.0 到 1.06）。
- 间奏结束前大约 0.5 秒，三个点先放大一下再收缩消失，下一行接着亮起。

### 5.6 翻译、音译的对齐

- **按时间对齐**：翻译、音译各自带时间轴，每行取与原文时间重叠最多的那一行（各轨的偏移先换算到同一时钟；没有结束时间的行算到下一行开始）。任一方没有时间轴时，按非空行的序号对齐。已用示例歌词验证（`CurrentLyrics::buildLines`）。
- **选轨**：原文优先用增强版（可能有逐字时间），翻译、音译优先用普通版；音译增强版里按音节计时的行另外用于注音（§6.3 第 7 条）。
- **空行**：不显示，只标出前一行在哪里结束，用来算间奏（每行的 `gapMs`）。
- **找不到对应原文行**：这一行翻译或音译就不显示，不另起一行。

### 5.7 没有歌词时

`Loading`、`NoLyrics`、`Instrumental`、`Failed` 各自显示一句话，位置和当前行一致：

| 状态 | 显示 |
| --- | --- |
| `Loading` | 骨架行 |
| `NoLyrics` | "暂无歌词" |
| `Instrumental` | "纯音乐，请欣赏" |
| `Failed` | "歌词加载失败"，带"重试"按钮 |

## 6. 日语音译：注音式（P9）

### 6.1 样式

- **位置**：罗马音以小字写在对应的假名或汉字正上方，类似振假名（ruby）。
  - 字号是原文的 42%，次要内容色；高亮时跟着下方的字一起变亮。
  - 每个假名单位各有自己的注音。连续的一串汉字共用一段注音（整组注音，§6.3）。
- **宽度**：每个单位是一个小块，注音在上、原文在下，注音相对原文居中。注音比原文宽时，这个小块按注音的宽度展开，原文居中。
- **行距**：只有用了注音的行在上方留注音的高度，其他行（罗马音退回原文下方的、没有罗马音的）都不留。原定"一首歌只要有一行用了注音，其余行也预留，保证行距一致"，维护者实际看后两次发现这块空白多余（2026-11-09：先是罗马音在下方的行，后是没有罗马音的行），取消。

### 6.2 适用范围

- **只对日语开启**：歌词里出现假名，就判定整首是日语歌。
- **逐行判断**：对齐成功的行用注音；失败的行退回为原文下方单独一行。
- **其他语言**：中文拼音、粤语注音以后也可以用这套样式，是否开启另行决定。

### 6.3 对齐算法

思路（维护者提出）：假名的读音基本固定，所以先给假名对上罗马音，夹在假名之间剩下的罗马音就是汉字的读音。这比查词典更可靠：歌词常有当て字和特殊读法（「本気」唱作 maji、「地球」唱作 hoshi），词典只会给出标准读音，而网易云的罗马音是按实际唱法写的。这样做也不需要附带词典。

**1. 切分原文**：把一行原文切成单位。

| 单位 | 说明 |
| --- | --- |
| 假名 | 拗音（きゃ）、促音（っ 和后面的假名）、长音符（ー）与前面的假名合成一个单位 |
| 汉字串 | 连续的汉字（包括々） |
| 带读音的汉字串 | 汉字串后面紧跟括号，括号里只有假名，例如「運命(さだめ)」「本気（マジ）」 |
| 拉丁字母与数字 | 原样匹配，作为额外的锚点 |
| 标点、空白 | 跳过 |

**2. 每个假名单位允许几种写法**：

| 类别 | 例子 |
| --- | --- |
| 助词 | は：wa／ha；へ：e／he；を：o／wo |
| 拼写体系 | し：shi／si；つ：tsu／tu；ふ：fu／hu；じ：ji／zi |
| 长音 | おう、ー：ō／ou／oo／o |
| 促音 | 下一个辅音重复：きって → kitte |
| ん | 后接元音或 y 时写作 n'，其余写作 n |
| 外来语片假名 | ティ：ti／thi；ファ：fa |

**3. 统一罗马音文本**：小写，去掉空格、撇号和连字符，长音符号展开（ō 换成 ou）。网易云的罗马音常按词加空格，不可靠，不作依据。

**4. 动态规划匹配**：从左到右，把罗马音文本分给各个单位。

- 假名单位必须匹配它的某种写法。
- 汉字串匹配一段任意长度的罗马音，至少一个音节。
- 带读音的汉字串：读音已知（括号里的假名按第 2 步的写法匹配），不参与猜测。
- 拉丁字母原样匹配，不分大小写。
- 有多种分法时，优先让汉字串分到的长度接近"汉字数 × 2 个音节"。

**5. 成功的条件**：所有锚点（假名、拉丁字母）都匹配上，而且整行罗马音恰好用完。任何一处对不上，这一行就退回单独一行。网易云的罗马音偶尔漏词，分行也可能和原文不一致，这条保险必须有。

**6. 显示**：

- 带读音的汉字串：显示时去掉括号部分，读音转成罗马音写在汉字上方。
- 不满足条件的括号照常显示，比如和声「(oh yeah)」，或括号里有汉字。

**7. 数据来源的优先级**：

1. 音译有逐字轨，而且音节带时间：按时间对应到原文的字上，最可靠。
2. 只有逐行音译：用上面的文本匹配。
3. 都不行：单独一行。

**8. 实现位置**：C++ 展示层，每首歌加载时算一次，结果作为每行的注音单位交给界面（`App.lyrics` 的行数据）。

**9. 示例与检查**：用示例歌词覆盖以下情况，逐一检查：助词、拗音、促音、长音、括号读音、和声括号、夹杂英文、罗马音漏词。

**实现（2026-11-05）**：`ui/presentation/ruby.cpp`。

- 汉字串按"每字约 3.5 个字母"计代价；假名优先第一种读法；省略长音（读法为空）代价较高，只在别的分法都不行时才用（否则「もう一回」会把 u 分给汉字）。
- 罗马音里的长音符号映射回原文，注音显示原文的写法（如「東京:tōkyō」）。
- 示例歌词 `so-031` 的 11 行里，10 行对齐成功；故意漏词的最后一行退回单独一行。两行带音节计时的按时间对齐，能细到每个汉字（「夜:yo」「空:zora」）。

**以后**：如果想把整组注音拆到每个字，或者给没有罗马音的日语歌生成罗马音，可以加词典作为补充，第一版不做。

## 8. 队列

右下角的"队列"打开侧边面板（`PlayerSheet`，和显示设置同一种面板，从右侧滑入，盖在歌词上；点旁边或 `Esc` 关闭，焦点回到按钮）：

- 整个队列按随机后的实际播放顺序排列，不分已播放、正在播放、接下来播放。正在播放的一行是选中态，末尾有 `graphic_eq` 图标。打开时这一行在顶部附近；换歌时自动滚过去，鼠标停在列表上时不动。
- 每行是 MD3 列表项（`ListItem`）：小封面、歌名、歌手，用封面派生的配色（`ColorScope`）。整个列表是一个 Tab 停留点，`↑`、`↓` 移动焦点环。
- **单击**或 `Enter` 播放这一首（2026-11-07 起不再需要双击）。
- **排序**：悬停时左边出现拖动手柄，拖到别处时显示一条插入线，松开才移动（和"调整顺序"页一样）；拖到列表边缘会自动滚动。键盘用 `Alt+↑`、`Alt+↓`。顺序播放时移动的是队列本身，随机播放时移动的是打乱后的顺序。
- **删除**：悬停时右边出现删除按钮，也可以用 `Delete` 或右键菜单。删除正在播放的歌曲时接着播下一首。无法播放的歌曲（灰色的行）同样能删除。
- **清空**（2026-11-10）：面板标题右边的 `clear_all` 按钮（队列有歌时出现），确认"清空播放队列？"后停止播放、队列清空（`App.player.clearQueue()`）。
- **加歌**（2026-11-10，FR-019）：歌曲列表右键菜单的"下一首播放"（插在正在播放的这首之后）和"加到播放队列"（加在末尾），多选时对选中的几首；带上列表的来源（听歌上报用）。队列为空时直接开始播放。私人 FM 时提示"私人 FM 不能加入队列"。`App.player.addSongs(keys, next, origin, originId)`；后端是 `ListeningSession::append`，登录切换中保留的队列（`Kept`）也照样插入。已在队列里的歌再加一次会出现两次（队列允许重复）。真实后端下验证过：插入位置、末尾追加、换歌后顺序、清空后不再续播、空队列加歌开始播放。
- 私人 FM 的队列不能编辑。
- 播放一行用 `App.player.playAt`，不改队列和顺序。右键菜单（菜单键、`Shift+F10` 也可以）有播放、查看歌手、查看专辑、加入歌单，用 MD3E 组件，套用从封面派生的配色。

### 9.1 入口

做法说明：

- **滚轮**：改由歌词上方一层只收滚轮的 `MouseArea` 处理（不挡悬停和点击）；触控板按像素、滚轮按格（约两行）。离屏测试里滚轮本来就能用，真机上不能用的原因没有找到，需要你再试一下。
- **悬停与水波纹**：悬停层改用 `StateLayer`（大圆角，点击有水波纹），左右各伸出 20；歌词区左右各放宽 20，裁剪不再切掉它。
- **居中不生效**：运行中切换对齐时，逐字排版没有重新排；现在对齐变化会重排。新增"靠右"。
- **上浮**：每个字在自己的时长里沿正弦缓动曲线上浮，并提前 300 毫秒起步，唱到一个字时后面一两个字已经开始抬起，形成一道波浪。
- **光晕锯齿**：图层放大时用的是最近邻采样；歌词的几处图层都改为平滑采样（`layer.smooth`）。
- **跳过很多行**：原来每行按与当前行的距离延迟起步，跳得远时延迟长达一秒多，远处的行又从屏幕外飞进来。现在跳过 3 行以上时，所有行移动相同的距离（最多 60% 的高度）、整块滑入，同时整体淡入，盖住瞬间离开的旧行；普通换行的延迟最多 8 行。
- **退出时的迷你播放条**：面板在最后 30% 的行程里淡出，迷你播放条的内容逐渐透出来，不再等面板完全消失才出现。
