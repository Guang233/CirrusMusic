# 发现页设计（已评审，2026-11-02）

**维护者已定**：D1–D6 按建议。另：所有歌单的详情页都显示播放量（歌单页头部的"播放 N 次"已有，后端的歌单详情带 `playCount`；假数据给账号自己的歌单补上了）。

首页回答"我现在听什么"，发现页回答"还有什么可听"（[home.md §1](home.md)）：按公共目录逛歌单、榜单、歌手和新碟。首页各推荐区块的"查看全部"都进这里的对应标签。现在的发现页是原型（与首页共用 `FeedPage`，几行卡片），本设计替换它。

## 1. 后端能给什么

| 内容 | 接口 | 说明 |
| --- | --- | --- |
| 歌单（按分类） | 歌单列表：分类、最热／最新、分页（offset），带总数（可能缺） | [playlist-discovery-reads.md](../../api/playlist-discovery-reads.md) |
| 精品歌单 | 精品列表：分类、游标分页（上一页最后一个的更新时间） | 有自己的标签表；不是每个分类都有 |
| 分类 | 分类目录（全部＋按组：语种、风格、场景、情感、主题），热门标签，精品标签 | 组的名字由目录给 |
| 推荐歌单 | 个性化推荐，一次最多 30，不分页 | 首页已经有 |
| 榜单 | 全部榜单（是歌单），部分带前三名的文字预览 | [chart-reads.md](../../api/chart-reads.md) |
| 歌手 | 按类型（男、女、组合）、地区（华语、欧美、日本、韩国、其他）、首字母（A–Z、#）筛选，分页；热门歌手 | [discovery-browse-reads.md](../../api/discovery-browse-reads.md) |
| 新碟 | 按地区（全部、华语、欧美、韩国、日本）分页；新碟周榜／月榜（按地区、年月） | 同上 |
| 没有的 | 轮播横幅、最新单曲（新歌速递）、MV、主播电台推荐 | 不做 |

都不需要登录（游客也能逛）。

## 2. 版式

```
发现
 歌单   排行榜   歌手   新碟                                    ← 标签，滚动后固定在顶部
──────────────────────────────────────────
（标签内容）
```

- 标题"发现"（headlineMedium），下面四个标签（MD3 主标签）。与音乐库、搜索页同一套：滚动后标签固定在顶部，Ctrl+PageUp／PageDown 切换，外壳记住上次的标签；每个标签第一次显示时才请求，各自有加载、失败、空状态。
- 首页"查看全部"：推荐歌单 → 歌单，榜单 → 排行榜，新碟上架 → 新碟，热门歌手 → 歌手。
- 不做"推荐"标签：个性化推荐是首页的事，发现页只放公共目录（D1）。

## 3. 各标签

### 3.1 歌单

```
(全部) (华语) (流行) (摇滚) (民谣) (电子) (轻音乐) (夜晚) …  [▦ 全部分类]     [最热|最新|精品]
┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐
│ ▶12万│ …                                                    ← 卡片网格，滚到底分页
└────┘
```

- **分类**：一行筛选纸片（MD3 筛选纸片，单选）：全部＋热门标签（最多一行放得下的个数，窄窗口时更少）。行尾"全部分类"（Tonal 按钮）打开对话框：按组（语种、风格、场景、情感、主题）列出全部分类，每组一段纸片，点一个就选中并关闭。选中的分类不在热门标签里时，作为第二个纸片临时出现在"全部"后面，让人看得出现在在哪个分类（D2）。
- **排序**：右侧三段按钮组（ConnectedButtonGroup，与纸片行同高）：最热、最新、精品。"精品"只在当前分类有精品歌单时可用（以精品标签表为准，"全部"总是可用），不可用时说明"这个分类没有精品歌单"（工具提示）（D3）。
- **卡片**：与首页的歌单卡片相同（封面、标题、"N 首"）；后端给了播放量时，封面左下角写"▶ 12万"（labelSmall，封面上的半透明 scrim 小牌子，MD3 的图片上文字做法）（D4）。
- 分页：最热、最新按 offset；精品按游标（上一页最后一张的更新时间），游标不前进或缺失时停止，显示"没有更多了"，不猜。

### 3.2 排行榜

```
官方榜
┌──────┐ 飙升榜                    每天更新      ┌──────┐ 新歌榜 …
│ 封面  │ 1 落日航线 - 雾港乐队                    │      │
│      │ 2 Harbor Lights - 雾港乐队               │      │
└──────┘ 3 星屑 - 星屑合唱团                      └──────┘
全部榜单
┌────┐ ┌────┐ ┌────┐ …                                       ← 卡片网格，副标题是更新频率
```

- **官方榜**：带前三名预览的榜单（后端给了预览的那几个，一般是 4 个）做成宽卡片，两列：封面、榜名、更新频率、前三名（序号 primary，"歌名 - 歌手"，预览是服务端给的文字，不能点到歌曲）。点卡片进榜单（歌单页）；卡片右上角播放按钮播放整个榜单。
- **全部榜单**：其余榜单是卡片网格，副标题是更新频率（如"每周四更新"）。
- 榜单一次全部返回，不分页。

### 3.3 歌手

```
语种  (全部) (华语) (欧美) (日本) (韩国) (其他)
分类  (全部) (男歌手) (女歌手) (乐队组合)
首字母 [热门 ▾]                                               ← 下拉纸片
( )( )( )( )( )( )                                          ← 圆形头像网格，滚到底分页
```

- 三个筛选：语种、分类是两行单选筛选纸片，行首是标签（labelLarge、onSurfaceVariant）；首字母是一个**下拉筛选纸片**（MD3 筛选纸片带下拉箭头），点开菜单：热门、A–Z、#（D5）。默认全部、全部、热门＝热门歌手。
- 卡片与搜索结果的歌手卡片相同（圆形头像、名字）。

### 3.4 新碟

```
(全部) (华语) (欧美) (韩国) (日本)                         [最新|本周热门|本月热门]
┌────┐ ┌────┐ …                                            ← 专辑卡片网格
```

- 地区是一行单选筛选纸片；右侧三段按钮组：最新（新碟列表，分页）、本周热门、本月热门（新碟榜的周榜、月榜，本月；一次返回，最多几百张，不分页）（D6）。
- 卡片与首页"新碟上架"相同（封面、标题、"歌手 · 年份"）。

## 4. 状态与键盘

- 加载：标签内容的骨架是卡片网格（与首页的卡片骨架相同）；筛选变化时网格原地替换（保留旧内容直到新内容到达，避免闪回骨架）。
- 失败：标签内的失败和重试；某个筛选组合没有结果："这个分类还没有歌单"等。
- 键盘：标签栏、纸片行、按钮组、网格卡片依次是 Tab 停留点；纸片行内 ←／→ 移动（与标签栏相同的做法，一行一个停留点），Space／Enter 选中。

## 5. 不做的

- 推荐标签、轮播横幅、新歌速递、MV、主播电台：首页已有推荐；其余后端没有接口或不在音乐功能范围。
- 歌单的多选分类、按歌单名查找：后端一次只按一个分类。

## 6. 需要决定

| 编号 | 问题 | 建议 |
| --- | --- | --- |
| D1 | 要不要"推荐"标签（网易云的"个性推荐"）？ | **已定：**不要。首页已经是推荐；发现页只放公共目录，两页不重复 |
| D2 | 歌单分类：一行热门纸片＋"全部分类"对话框，还是只有对话框（网易云）？ | **已定：**纸片＋对话框。常用分类一键可达，完整目录在对话框里 |
| D3 | 精品歌单：作为排序的第三段，还是单独的入口卡片（网易云在列表上方放一张"精品歌单"横幅）？ | **已定：**第三段。同一个网格里切换，不多一层页面 |
| D4 | 歌单卡片显示播放量（封面上的小牌子）？ | **已定：**显示。发现页逛歌单时播放量是主要参考；首页的推荐卡片不加，保持简洁 |
| D5 | 歌手的首字母：下拉筛选纸片，还是一整行 A–Z（网易云）？ | **已定：**下拉。一整行 28 个纸片在桌面上会换成两三行，占地方又难扫读 |
| D6 | 新碟要不要周榜／月榜？ | **已定：**要，作为"本周热门／本月热门"两段；后端已有接口，比单纯按时间排的新碟更有用 |

## 7. 实现时的改动（评审后）

- 展示层：`CatalogSource` 加 `playlistCategories()`（目录＋热门标签＋精品标签）、`categoryPlaylists(category, order, page)`、`premiumPlaylists(category, cursor)`、`charts()`（带预览）、`artistBrowse(type, area, initial, page)`、`newAlbums(area, page)`、`albumChart(area, monthly)`；发现页一个页面模型，四个标签各一个子模型（筛选是它们的属性，改了就原地重新加载）。
- 控件：`Chip` 加下拉样式（尾部 `arrow_drop_down`，点开菜单；MD3 筛选纸片的变体），`CollectionCard` 加可选的播放量牌子。纸片行做成一个组件（单选、一个 Tab 停留点、←／→ 移动）。
- 首页：各"查看全部"打开发现页的对应标签。
- 图标：`arrow_drop_down`、`grid_view`（全部分类）加入 `symbols.txt` 后重新生成。
