# 专辑页与每日推荐页设计（已评审，2026-11-01）

两页沿用歌单页的版式（[playlist.md](playlist.md)：头部、操作行、桌面表格、按页状态、键盘与多选），本文只写不同之处。[playlist.md §8](playlist.md) 的对照表以本文为准。

**维护者已定**：A1–A3 按建议；A4 改为**做历史日推**（"我们要做的是完整的网易云客户端"），见 §2.1。两页都**不能排序**（列标题不可点，也没有"调整歌曲顺序"，它们不是自建歌单）；**保留查找**（操作行最右的查找框和 Ctrl+F）。

## 1. 专辑页

```
┌────────┐  专辑                                       ← 后端的类型：专辑／EP／单曲
│        │  Tidal Memory                              ← headlineLarge
│  封面  │  Lumen Avenue / 雾港乐队                    ← 每位歌手可点（链接样式）
│  200   │  2024年5月1日发行 · 某某唱片
│        │  12 首 · 48 分钟
└────────┘  一行介绍……                         更多     ← 有介绍时；"更多"打开介绍对话框
[▶ 播放全部] [收藏] [评论 128]                [🔍 在专辑中查找]
 #  标题                                         喜欢   时长   ⋯
 1  海风写给你的信                                 ♡    2:37
    雾港乐队
```

- **头部**
  - 类型行用后端的 `type`（专辑、EP、单曲），没有时写"专辑"；有别名时跟在标题下一行（小字）。
  - 歌手：多位用" / "分隔，每位单独可点，进歌手页。
  - 日期行："2024年5月1日发行 · 唱片公司"，缺哪项省哪项。
  - 数字行：首数和总时长（由歌曲时长相加；有未知时长时只写首数）。
  - 介绍：与歌单页的描述相同（一行，"更多"打开对话框）。
- **操作行**
  - 播放全部、收藏／已收藏（`AlbumSubscribe`／`AlbumUnsubscribe`；是否已收藏从音乐库"收藏的专辑"得知，与歌单的收藏按钮同样处理）、评论（有数字时写数字；点开仍提示评论页在设计中）、查找框。
  - 没有"更多"菜单（没有可编辑的东西）。
- **表格**
  - 不显示封面列和专辑列（都是这张专辑）；腾出的宽度给标题。
  - 序号是专辑里的曲序；查找时显示原曲序，不重新编号。
  - 标题格仍是两行：歌名（加别名），第二行歌手。合辑里每首歌手不同，两行也让行高与其他页一致（A1）。
  - 列标题不可点、没有排序箭头。
  - 行菜单：去掉"查看专辑"和"从歌单移除"，其余照旧（播放、下一首播放、喜欢、收藏到歌单、查看歌手）。
- **碟号分组**：后端的歌曲没有碟号字段，先不分组（A2）。
- 骨架、加载失败、无版权行、红心、多选、键盘都与歌单页相同。专辑的歌曲随详情一次返回，不需要按页补详情。

## 2. 每日推荐页

```
┌────────┐  每日推荐
│   1    │  根据你的口味生成，每天 6:00 更新
│ 11月·日 │  30 首 · 1 小时 52 分钟
└────────┘
[▶ 播放全部]                                   [🔍 在推荐中查找]
 #  标题                  推荐理由              专辑          喜欢  时长  ⋯
 1  [封] 落日航线          根据你喜欢的单曲推荐     落日航线        ♡   3:41
         雾港乐队
```

- **头部**
  - 封面位置换成日期块：与首页"今日"卡片同一种写法（大号细体日期数字，下面"11月 · 星期日"），200×200，`primaryContainer` 底色、`shape.extraLarge` 圆角。
  - 标题"每日推荐"，一行说明"根据你的口味生成，每天 6:00 更新"，数字行同专辑页。
  - 没有创建者、标签、介绍。
- **操作行**：播放全部、查找框。没有收藏、评论、"更多"。
- **表格**
  - 与歌单页相同（封面、专辑列都在），多一列**推荐理由**，放在标题和专辑之间；窗口窄到放不下专辑列时，理由列也不显示（A3）。没有理由的歌这一格空着。
  - 列标题不可点。行菜单与歌单页相同，去掉"从歌单移除"。
- **未登录**：每日推荐需要登录。页面显示空状态："登录后，这里每天都有一组为你挑的歌"＋"扫码登录"按钮（与首页"今日"卡片同一句话）；登录成功后自动加载。在页面上退出登录时回到这个状态。
- **跨天**：停在页面上不自动刷新；下次进入（或从别的页面返回）时，如果已经过了 6:00 的更新点就重新加载。
- 网易云的"不感兴趣"后端没有接口，不做。

### 2.1 历史日推（A4）

后端有两个读接口：可用日期列表（`YYYY-MM-DD`）和某个日期的歌曲（没有推荐理由）。只能读列表给出的日期；能读多少天、是否要会员，后端文档写明未知，被拒绝时**不能**断言是会员原因。

- 每日推荐页操作行"播放全部"后面加 Tonal 按钮"历史日推"（图标 `history`）。点开时请求日期列表，弹出菜单：最近的在上，每项"10月31日 星期五"，当前看的那天打勾；请求中菜单里是一行灰的"正在加载…"。日期列表为空时一行灰的"还没有历史日推"；失败时关菜单、提示条"没能获取历史日推"（被拒绝时"历史日推暂时不可用"，不写会员）。
- 选中日期进入那天的历史日推（新的一页，进历史，可后退回今天）：日期块显示那天，标题"历史日推"，说明行"10月31日的每日推荐"；没有理由列（所有歌都没有理由时自动不显示）。操作行同样有"历史日推"按钮，可以换一天（替换当前页，不叠加历史）。
- 未登录、加载状态与今天的页面相同。

## 3. 需要决定

| 编号 | 问题 | 建议 |
| --- | --- | --- |
| A1 | 专辑页标题格是否总显示第二行歌手？Apple Music 只在歌手与专辑歌手不同时显示，行更紧凑 | **已定：**总显示。合辑常见，行高与歌单、每日推荐一致，表格代码也不用分两种行 |
| A2 | 多碟专辑按碟分组？ | **已定：**先不分组。后端歌曲没有碟号；要做需要后端从详情里补上碟号字段，之后再加分组标题（"碟 1"） |
| A3 | 推荐理由放独立列，还是放在标题格第二行歌手后面？ | **已定：**独立列，窄窗口隐藏。理由是读完一行就懂的短句，独立列便于扫读；挤进第二行会和歌手混在一起 |
| A4 | 是否做历史日推入口？ | ~~先不做~~ **已定：做**（§2.1） |

## 4. 实现时的改动（评审后）

- `SongTable` 加 `sortable`（列标题是否可点）、`showCover`、`showAlbum` 改为可由页面关掉、可选的理由列（`showReason`）；序号取原顺序（已是）。
- 展示层：`AlbumInfo` 加 `type`、`aliases`、`publishedAtMs`、`company`、`subscribed`、`commentCount`；`AlbumPageModel` 加收藏（`LibrarySource::setAlbumSubscribed`，假实现）；每日推荐的模型改用 `SongListModel` + `SortedSongsModel`（只用查找）。
- 首页"今日"卡片的日期写法抽成组件，两处共用。

## 5. 实现进度（2026-11-01）

已按本文实现，与 §4 的差别：

- 三页共用的版式抽成 `ui/app/SongCollectionPage.qml`（头部、操作行、查找、紧凑条、骨架、空状态），头部各部分由页面以组件提供（`infoContent`、`extraContent`、`actionsContent`、`noticeContent`）；`PlaylistPage` 也改用它，行为不变。Ctrl+F 对三页都有效。
- `SongTable` 加 `sortable`、`showCover`、`albumColumn`、`reasonColumn`（理由列在标题与专辑之间，随专辑列隐藏）、`numberByPosition`（`SongListModel` 新的 `position` 角色）。
- 日期块是新组件 `DateTile`（大、中、紧凑条三种尺寸）；首页"今日"卡片有字重动画和自己的排版，没有改用它。
- 展示层：`AlbumInfo` 加 `type`、`aliases`、`publishedAtMs`、`company`、`commentCount`、`subscribed`；`LibrarySource::setAlbumSubscribed`；`CatalogSource::dailyHistoryDates`、`dailyHistorySongs`；`DailySongsPageModel` 加 `date`、`hasReasons`、`countText`、`historyDates`、`loadHistoryDates()`、`reloadIfStale()`；`Formatter` 加 `fullDate`、`totalLength`；`PageState` 加 `signedOutText`。
- 假数据：示例目录没有的专辑字段（类型、发行日、唱片公司、介绍、评论数）在 `fake_sources.cpp` 里按专辑在目录中的位置固定生成；历史日推为最近 7 天（跳过一天），歌曲按日期固定挑选。
- 验证：构建、qmllint、clang-format；离屏截图检查了专辑页（宽、窄、两位歌手、查找保留曲序）、每日推荐（登录、未登录、紧凑条）、历史日推菜单与键盘选择、历史日页面（无理由列），以及重构后的歌单页（排序、提示条）。
