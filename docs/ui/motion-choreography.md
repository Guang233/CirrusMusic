# 过渡编排说明

> 状态：设计稿（2026-10-26），阶段 3、4 按此实现，原型中调整的参数回写本文。弹簧令牌和 `Spring` 元素见 [theme.md §6](theme.md)，控件自身的状态动效见 [controls.md](controls.md)。

本文只写**跨组件**的动画：几个元素一起动，要规定谁先动、谁跟随、用哪档弹簧、被打断时怎么办。单个控件内部的动效（按钮变形、开关滑动、菜单展开）不在这里。

## 1. 通用规则

### 1.1 令牌选择

| 动作 | 空间（位置、尺寸、缩放、圆角） | 效果（透明度、颜色） |
| --- | --- | --- |
| 迷你播放条 ↔ 播放页（全屏、标志性） | `slowSpatial`（打开）／`defaultSpatial`（关闭） | `slowEffects`／`defaultEffects` |
| 页面前进、返回、切换顶层目的地 | `standardDefaultSpatial` | `defaultEffects`，淡出用 `fastEffects` |
| 导航栏展开收起（推挤内容时） | `standardDefaultSpatial` | `fastEffects` |
| 导航栏展开收起（浮层模式，不推挤内容） | `defaultSpatial` | `fastEffects` |
| 切歌换色 | — | 外壳沿用主题混合（`defaultEffects`），播放页背景 `slowEffects` |
| 内容加载完成（骨架屏 → 内容） | — | `fastEffects` |

- **会改变其他元素布局的尺寸动画用标准方案**（过冲约 0.2%，看不出来）。Expressive 方案过冲 1.5%–9.5%，用在推挤布局的宽高上会让整列内容跟着回弹，既难看又要逐帧重排。
- **不推挤布局的元素用 Expressive 方案**：飞行中的封面、浮层、变形的形状。
- 时长只是参考（theme.md §6 的稳定时间）。弹簧没有固定时长，编排按“进度区间”描述，不按毫秒描述。

### 1.2 进度驱动与打断

一次跨组件过渡由**一个 0–1 的进度弹簧**驱动，所有元素的属性都从这个进度派生：

```qml
Spring { id: open; target: player.opened ? 1 : 0; spec: player.opened ? Theme.motion.slowSpatial : Theme.motion.defaultSpatial }

// 区间映射：p 在 [a, b] 内线性映射到 0–1，区间外截断
opacity: Theme.motion.segment(open.value, 0.55, 1.0)
// 几何属性不截断，允许跟随弹簧过冲
x: Theme.motion.lerp(miniRect.x, fullRect.x, open.value)
```

- **打断**：改 `target` 即可。`Spring` 从当前位置和速度继续（theme.md §6），所有派生属性一起平滑反向，不会出现“A 已经反向、B 还在前进”的错位。中途换 `spec` 同样保留速度。
- **只有颜色、透明度需要截断**：透明度超出 0–1 没有意义，所以用 `segment`（截断）；位置、尺寸用 `lerp`（不截断），保留弹簧的过冲手感。
- 确实需要不同弹簧的元素（例如封面用空间弹簧、背景颜色用效果弹簧）各用一个 `Spring`，但**目标绑定同一个状态**，打断时一起改向。
- **交互不等动画结束**：目标状态一确定，新界面立即接受点击和键盘输入，旧界面立即停止接受；不设“动画期间锁住输入”。
- **不要用 `Behavior` 串联跨组件动画**，也不要用 `SequentialAnimation` 写时间线：它们被打断时只能跳到终点或从头开始。

`Theme.motion.segment` 与 `Theme.motion.lerp` 是两个纯计算的辅助函数（无状态）。

### 1.3 减少动态效果

`Theme.motion.reduced` 为真时，空间弹簧会直接跳到目标（`Spring` 已实现），效果弹簧照常运行。因此：

- 每个过渡都要设计“减少动态效果”版本：**位移、缩放、共享元素飞行一律取消**，改为用效果弹簧做交叉淡入淡出。
- 实现方式：减少动态效果时，几何属性直接取终点值，透明度改由一个效果弹簧（`defaultEffects`）驱动。不要依赖“空间弹簧跳到终点”顺带完成淡入，那样会变成硬切。
- 外壳配色在减少动态效果时立即切换（theme.md §2 已实现）；播放页背景静止、不流动。

### 1.4 渲染与性能

- 动画期间只改 `x`、`y`、`scale`、`opacity`、`clip` 圆角，不改会触发布局重排的属性（导航栏推挤内容是唯一例外，见 §5）。
- 需要整体淡入淡出的复杂子树，在过渡期间临时开 `layer.enabled`，结束后关闭，避免子项各自半透明叠加出“透视”效果。
- 软件渲染（没有着色器）时：模糊、流动背景退回为由取色结果生成的静态渐变；共享元素飞行照常（只用到普通 `Image`）。

## 2. 迷你播放条 ↔ 播放页

最复杂的一个过渡。目标：封面从迷你条的位置“飞”到播放页的位置，背景从迷你条铺满窗口，两种设计语言在这一段完成交接。

### 2.1 结构

```text
Main（窗口）
├─ AppShell          外壳：标题栏、导航栏、页面栈、迷你播放条
├─ PlayerPage        播放页：始终按最终布局排好，平时不可见
└─ TransitionLayer   过渡层：在两者之上，只在过渡期间有内容
   ├─ 背景面板        从迷你条矩形长到整个窗口
   └─ 代理封面        同一张图、同一个图片 key，在两个位置之间飞行
```

- 播放页常驻并保持最终布局，所以封面的终点矩形随时可以读到；用 `mapToItem(transitionLayer, …)` 取迷你条封面和播放页封面在过渡层坐标系里的矩形。两者都写成绑定，窗口在过渡中缩放时终点自动更新。
- 过渡期间真实的两个封面都隐藏，只显示代理封面，避免同一张图出现两次。
- 进度 `p`：打开时目标 1，关闭时目标 0。打开用 `slowSpatial`，关闭用 `defaultSpatial`（关闭要比打开利落，参考 Apple Music）。

### 2.2 时间线（打开；关闭是同一条时间线倒放）

| 元素 | 属性 | p 区间 | 映射 |
| --- | --- | --- | --- |
| 迷你条文字、按钮 | 透明度 1 → 0 | 0 – 0.2 | segment |
| 背景面板 | 矩形：迷你条矩形 → 整个窗口；圆角：迷你条圆角 → 0 | 0 – 1 | lerp |
| 背景面板 | 颜色：迷你条容器色（MD3 surfaceContainer）→ 播放页背景 | 0 – 0.5 | segment，交叉淡入 |
| 代理封面 | 矩形：迷你条封面 → 播放页封面；圆角：迷你条圆角 → 播放页封面圆角 | 0 – 1 | lerp |
| 外壳内容 | 透明度 1 → 0（被背景完全盖住后才隐藏，省绘制） | 0.5 – 0.6 | segment |
| 播放页歌曲信息、控制区 | 透明度 0 → 1，向上位移 16 → 0 | 0.55 – 1 | segment |
| 歌词／队列面板 | 透明度 0 → 1 | 0.65 – 1 | segment |
| 自绘标题栏的窗口按钮 | 颜色：外壳前景色 → 播放页前景色 | 0.3 – 0.7 | segment |

- **背景颜色**：交叉淡入的终点是播放页背景层本身（模糊封面或流动渐变），不是一个纯色；背景层的动画在 `p > 0` 时才启动，`p` 回到 0 后停止。
- **结束时交接**：`p` 稳定在 1 后，隐藏代理封面、显示播放页真实封面、清空过渡层；稳定在 0 时反之。两个封面同尺寸同图片，交接不可见。
- **焦点**：打开时键盘焦点移到播放页的播放/暂停按钮；关闭时还给迷你条上“打开播放页”的按钮。读屏通过 `Accessible` 名称宣告“正在播放”页面。

### 2.3 打断与边界情况

- **中途反向**：Esc、返回键、再次点击迷你条，都只是改目标，从当前进度反向。
- **过渡中切歌**：代理封面换图做交叉淡入（`fastEffects`），飞行不中断、不重新开始。
- **过渡中缩放窗口**：起止矩形是绑定，自动跟随；不需要特殊处理。
- **找不到迷你条封面**（迷你条被隐藏、窄窗口里没有封面位置）：退化为整页从底部上移 48 并淡入，不做共享元素飞行。
- **向下拖动关闭**（触控板、触屏；阶段 4 视原型效果决定是否做）：拖动期间 `p` 直接跟随手指（拖动距离 ÷ 窗口高度）；松手时按速度和位置决定开或关，并把松手速度交给弹簧。`Spring` 目前没有“带初速度起步”的接口，届时需要加一个（如 `animateTo(target, velocity)`）。

### 2.4 减少动态效果

不飞行、不铺开：播放页整体用 `defaultEffects` 淡入，外壳在淡入完成后隐藏；关闭时反之。

## 3. 页面切换与返回

页面在外壳内容区里切换，导航栏、标题栏、迷你播放条不动。按 MD3 的两种模式：

| 场景 | 模式 | 旧页面 | 新页面 |
| --- | --- | --- | --- |
| 前进（进入详情、从列表打开歌单） | 横向共享轴 | 向左移 30、淡出（0 – 0.35） | 从右侧 30 移入、淡入（0.2 – 1） |
| 返回 | 横向共享轴，方向相反 | 向右移 30、淡出 | 从左侧 30 移入、淡入 |
| 切换顶层目的地（导航栏点击） | 淡出淡入 | 淡出（0 – 0.35，`fastEffects`） | 缩放 0.92 → 1、淡入（0.35 – 1） |

- 用一个进度弹簧（`standardDefaultSpatial`）驱动位移和缩放，透明度按上表区间截取。
- 位移量固定 30，不随窗口宽度变化，大窗口里也不会“甩”得太远。
- **不等数据**：点击后立即开始过渡，新页面先显示骨架屏（尺寸与真实内容一致），数据到达后骨架屏淡出、内容淡入（`fastEffects`），页面不跳动。
- **返回时恢复滚动位置**：在新页面开始过渡**之前**设好滚动位置，不在过渡中途跳动。
- **打断**：
  - 前进过渡中按返回：同一对页面反向播放，不新建页面。
  - 过渡中又发起新的导航：正在进入的页面立即变成“旧页面”，从当前状态开始淡出；原来的旧页面直接移除。同时参与过渡的页面最多两个。
- **减少动态效果**：所有页面切换都改为 `fastEffects` 交叉淡入淡出，没有位移和缩放。
- **暂不做**：列表封面到详情页头图的“容器变换”（container transform）。第一轮页面完成后再评估，届时补进本节。

## 4. 切歌时的取色过渡

切歌会同时引起三处变化：封面图片、外壳配色（仅当种子来源为“跟随封面”时）、播放页背景与文字颜色。三者用的是同一次取色结果（`Theme.coverPalette`），见 [theme.md §2](theme.md)。

### 4.1 顺序

1. **触发点**：播放快照里的当前歌曲变化时（而不是用户点击“下一首”时），设置新封面。
2. **封面先换**：新封面解码完成前保留旧封面；完成后两层交叉淡入（迷你条和播放页都用 `defaultEffects`）。由 `Cirrus.Components` 的 `CoverArt` 实现。
3. **颜色跟随**：取色完成（每张 1–7 ms，和解码几乎同时）后：
   - 外壳：主题自己的 CAM16-UCS 混合（`defaultEffects`，约 230 ms），已实现。
   - 播放页背景：交叉过渡到新背景（`slowEffects`，约 330 ms）。原型里如果觉得太快，用 `Theme.motion.custom` 放慢，并记进 [pages/player.md](pages/player.md)。
   - 播放页文字颜色：和背景**同一个进度**过渡。对比度要在起点、终点都达标；以白色系为主的前景在中间态也不会掉到不可读。
4. 颜色过渡不早于封面开始淡入，避免“颜色已经变了、封面还是上一首”。

### 4.2 打断与边界情况

- **快速连续切歌**：以最后一次为准。取色已经按编号丢弃过期结果；颜色混合从屏幕上当前的颜色继续（已实现）。封面交叉淡入只保留两层：新封面到达时，当前可见的那一层成为底层，不叠出第三层。
- **没有封面**：显示占位图；外壳退回系统强调色种子，播放页用中性深色背景。
- **减少动态效果**：外壳配色立即切换（已实现）；封面交叉淡入保留，缩短为 `fastEffects`；播放页背景静止，颜色直接换。

## 5. 导航栏展开与收起

MD3E 的导航栏（androidx `WideNavigationRail`）有收起和展开两种形态：收起宽 96，图标在上、标签在下；展开宽 220–360，图标和标签横排，选中指示条变成包住两者的长条。具体尺寸与颜色在实现 NavigationRail 控件时写入 controls.md。

两种用法，弹簧不同：

| 用法 | 窗口 | 对内容区 | 宽度弹簧 |
| --- | --- | --- | --- |
| 常驻展开 | large 及以上（≥ 1200） | 推挤内容，内容区宽度跟着变 | `standardDefaultSpatial` |
| 浮层展开 | medium、expanded（600–1199） | 盖在内容上，加遮罩，不推挤 | `defaultSpatial` |

**时间线（展开；收起倒放）**，`p` 为宽度弹簧的进度：

| 元素 | 属性 | p 区间 |
| --- | --- | --- |
| 图标下方的标签 | 透明度 1 → 0 | 0 – 0.3 |
| 导航栏 | 宽度 96 → 展开宽度 | 0 – 1 |
| 选中指示条 | 宽度、高度、位置 → 展开形态 | 0 – 1 |
| 图标右侧的标签 | 透明度 0 → 1 | 0.6 – 1 |
| 浮层遮罩（仅浮层模式） | 透明度 0 → 0.32 | 0 – 1 |

- 推挤内容时，内容区是逐帧重排的。页面要保证宽度连续变化时布局不抖动：不按宽度切换列数，列数只在宽度弹簧稳定后更新。
- **缩放窗口跨过断点时不播放动画**，直接切到新形态（`snapTo`），避免拖动窗口边缘时动画追不上。
- **打断**：再次点击展开按钮就反向。浮层模式下点击遮罩或按 Esc 收起。
- **减少动态效果**：宽度直接跳变，标签交叉淡入淡出。
