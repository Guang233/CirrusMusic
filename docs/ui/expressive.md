# 界面的表现力改造（待评审，2026-11-13）

状态：**待评审**。维护者 2026-11-13 提出"现在的 UI 还不够 Expressive"（例：Expressive 常把图标放在有底色的形状里），同意按"重点处大胆、内容区克制"的力度改，先静态（第 1、2 步）后动效（第 3 步），设计一次写全。

## 1. 现状

依据：2026-11-13 在真实应用里截的首页、发现、歌手、搜索、设置、播放页（GPU 渲染；本地 `build/research-scripts/ui-survey/`），以及控件代码。

**已经到位的（控件层）**：按钮的形状变化（按下圆↔方）、连接按钮组、分段列表（行间 2 px、首尾圆角）、形状变换的加载指示器、波浪进度条、m3shapes 的 35 种形状（`MorphShape`）、Expressive 和标准两套空间弹簧、2025 配色规范。侧栏的选中指示从中间长出、标签页指示条滑动，都已经是弹簧。设置页的分组索引给图标配了彩色圆底。

**不够的（页面层）**：控件有了，页面几乎没用上 Expressive 拉开层次的手段：

| | 现状 |
| --- | --- |
| 形状 | 除按钮外几乎都是圆角矩形；35 种形状只在加载指示器、登录框、FM 卡片里出现 |
| 图标 | 音乐库卡片、听歌统计、空状态和错误状态都是裸字形；`GlyphTile`（最近播放、听歌排行、听歌统计完整排行的"封面"）是方块上一个大字形 |
| 层次 | 强调字体令牌（`Theme.type.*Emphasized`，15 个）页面里一次都没用；详情页的主操作"播放全部"和其他按钮一样是 40 高的小号按钮 |
| 卡片 | 歌单卡片封面圆角 12（`Theme.shape.medium`），悬停只有一层叠色 |
| 动效 | 页面切换每页都是 30 px 横移加淡入（MD3 基线的共享轴）；页面里多是淡入淡出；只有首页的段落会上浮出现 |

## 2. 力度

**重点处大胆，内容区克制。** 封面已经是最强的视觉元素，大面积加彩色形状会和封面抢；桌面、键盘用户天天用的高密度列表要紧凑。所以：

- **大胆的地方（"点"）**：图标容器、空状态和错误状态、详情页的头部和主操作、`GlyphTile`、卡片的交互形状。
- **不动的地方**：歌曲表格、评论、播放队列、搜索建议的行高和密度；侧栏导航项（MD3 的导航项用选中指示，不给图标加圆底）；设置的选项行。
- 不用阴影分层（[[no-shadow-layering]]）；新东西都是 `Cirrus.Controls`／`Cirrus.Components` 的控件，页面不自己画（[[follow-md3e-spec]]）。

## 3. 基础组件（第 1 步）

### 3.1 图标容器 `IconContainer`（Cirrus.Components）

一个字形放在色调容器里，只显示、不可点（可点的用现有 `IconButton` 的 Filled／Tonal 样式，它本来就是圆底）。

| 属性 | 取值 |
| --- | --- |
| `glyph` | 字形 |
| `size` | 32、40、56、96（图标 18、22、28、48；比例照 `IconButton`） |
| `shape` | 默认圆；可选 m3shapes 的形状（`MaterialShape.Cookie9Sided` 等），软件渲染退回圆 |
| `tone` | `Primary`、`Secondary`、`Tertiary`、`Error`、`Neutral`：容器取对应的 `*Container`，图标取 `on*Container`；`Neutral` 是 surfaceContainerHighest＋onSurfaceVariant |
| `filled` | 图标实心（FILL 1），默认是 |

规则（E1）：40 及以下的小容器一律用圆；形状只用在 56 以上的装饰性大容器（空状态、`GlyphTile`），每种用途固定一种形状，不随机。

### 3.2 强调字体

令牌已有（`Theme.type.headlineLargeEmphasized` 等），定下用在哪（E5）：

| 位置 | 现在 | 改为 |
| --- | --- | --- |
| 详情页标题（歌单、专辑、歌手、歌曲、用户、播客） | headlineLarge | headlineLargeEmphasized |
| 顶层页标题（发现、音乐库、听歌统计、设置、搜索词） | headlineMedium | headlineMediumEmphasized |
| 段落标题（首页各段、歌曲页各段、听歌统计各段） | titleLarge | titleLargeEmphasized |
| 关键数字（听歌统计的时长、首页的日期） | display* | display*Emphasized |

正文、列表、按钮文字不变。

### 3.3 详情页的主操作

"播放全部"（`SongCollectionPage` 的各页）、"播放热门歌曲"（歌手页）、歌曲页的"播放"改成**中号**（56 高）Filled 按钮，带文字；同一行的其他按钮仍是小号，垂直居中（E2）。按钮自己的按下变形（圆→方）已有。不做 Spotify 那种只有图标的大圆钮：桌面上带文字更清楚。

### 3.4 卡片的形状交互

`CollectionCard` 的封面：静止圆角 `large`（16，现在是 `medium` 12），悬停 `extraLarge`（28），按下 `medium`（12），`fastSpatial`（Expressive，带一点过冲）在三者之间走（E3）。歌手卡片是圆形，不变。

### 3.5 空状态、错误状态

`StateMessage`（`PageState`、各段落都用它）的 48 号裸图标换成 96 的 `IconContainer`：

| 情况 | 形状 | 色调 |
| --- | --- | --- |
| 空（还没有内容） | `Cookie9Sided` | Secondary |
| 出错 | `SoftBurst` | Error |
| 离线 | `Cookie9Sided` | Neutral |
| 未登录 | `Cookie9Sided` | Primary |

### 3.6 `GlyphTile`（ui/app）

最近播放、听歌排行、听歌统计完整排行没有封面，头部的"封面"是一块 secondaryContainer 的圆角方块，上面一个占宽 42% 的实心字形。改为：方块换成 surfaceContainerHigh（和其他页的封面一样大、一样的圆角），中间放一个占宽 60% 的 `IconContainer`（形状 `Cookie12Sided`，Secondary）。紧凑栏里的小方块（宽 100 以下）不变。

gallery：`IconContainer`（各尺寸、形状、色调）、新的 `StateMessage`、卡片交互放进"数据与状态""按钮"页，属于设计因子。

## 5. 动效（第 3 步）

**令牌**照 [motion-choreography.md §1.1](motion-choreography.md) 的现有规则，不另立：推挤布局的尺寸变化用标准空间弹簧；不推挤布局的（飞行的封面、变形的形状、卡片圆角、图标缩放）用 Expressive 空间弹簧；颜色、透明度用效果弹簧。减少动态效果时按 §1.3：位移、缩放、飞行取消，改为交叉淡入淡出。

**要加的四处**：

1. **卡片到详情页的封面飞行**（E4）：motion-choreography.md §3 把"列表封面到详情页头图的容器变换"留到"第一轮页面完成后再评估"，现在页面已齐，这里就是那次评估。点歌单、专辑、歌手、播客卡片时，卡片封面从原位置飞到详情页头部封面的位置（位置、尺寸、圆角一起变，`defaultSpatial`），新页其余内容照常横移淡入；返回时飞回原卡片（卡片已不在屏幕上就只做普通的横移）。只在卡片→详情页；歌曲行（小封面）到歌曲页不做。做法照迷你播放条↔播放页（同一张图的代理封面在过渡层里飞，两端真实封面隐藏）。实现时写进 motion-choreography.md §3。
2. **卡片的形状交互**：3.4。
3. **段落依次出现**：首页 `HomeSection` 的上浮出现推广到歌曲页、听歌统计、音乐库的段落：内容第一次到达时上浮 16 px 并淡入（照 `HomeSection` 现有的写法），相邻段落错开一小段；刷新时不再播放。
4. **红心**：点喜欢时图标放大到 1.2 再回到 1（`fastSpatial`，带过冲）。限制：`Icon` 用原生渲染，缩放期间是位图缩放、会略模糊（[controls.md §2](controls.md)），时长短，可接受。

已有、不改：按钮按下变形、侧栏选中指示从中间长出、标签页指示条滑动、页面横移（封面飞行之外的情况）。
