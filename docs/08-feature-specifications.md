# 08 · 功能流程规格

> 状态：提案。本文补全需求矩阵中的业务流程；底层线程、错误与数据规则分别见 03～06、09。

## 1. 账号与登录（FR-002～005）

**前置条件**：内置官方协议可用；网络不可用时仍能进入本地功能。首次启动不要求用户填写 API 地址。

**正常流程**：游客首页 → 主动登录 → 创建二维码或接口支持的登录挑战 → 展示与轮询 → 用户授权 → 校验会话和身份 → 将凭据写入密钥环 → 切换 profile → 加载个人库。

**分支**：

- 二维码到期：显示刷新操作；新二维码使用新 request generation。
- 用户关窗：取消轮询，晚到成功不能悄悄登录。
- 密钥环不可用／用户拒绝：允许明确的“仅本次登录”，不把 Cookie 写进 QSettings。
- 额外验证／验证码：展示官方要求的合法流程；未实现则明确“需验证”，不死循环。
- 会话过期：私人列表可显示标为过期的已缓存快照，但不能继续远程写；不影响用户自有本地文件。
- 切号：先冻结写操作、停止旧账号授权播放并清理私有页面；新账号载入前不可出现上一账号歌单闪烁。

**后置条件**：只有服务端身份校验成功后才进入 Authenticated。保存会话失败不应让一次有效登录变成“已永久记住”。

## 2. 搜索与目录（FR-006～010）

- 搜索状态分为 Idle、Suggesting、Loading、Ready、Empty、Error；用户输入与已提交 query 分开。
- 建议防抖，正式 Enter 搜索立即提交；中文 IME composition 不提前当作完成输入。
- queryKey 包含关键词、结果类型、排序和账号范围；切换类型不会复用错误分页 cursor。
- 页面切换／新查询取消旧任务；结果按 generation 过滤。
- 大 ID 全程字符串，列表使用稳定 key；高亮以纯文本片段表示，不把远程标题直接拼进富文本 HTML。
- 专辑按碟号／曲号或官方顺序展示，不自行按标题排序；未知时长显示占位而非 00:00。
- 歌手／专辑／歌单的订阅态独立于歌曲喜欢态，不以同一布尔字段复用。
- 下架歌曲保留元数据与原因，点击播放得到明确结果；不要在后台悄悄从歌单删掉。

**播放全部**：确认全部 ID 或分页队列源已建立才启动对应上下文；不能将已加载的 20 条当成远程 1,000 首的全部。

## 3. 音乐库、喜欢与歌单编辑（FR-011～014）

### 3.1 喜欢／收藏

显示两种状态：服务端确认态与用户最新意图。允许乐观展示，但同一实体只保留一个执行链；后续点击合并为最新目标。成功时以服务端读取／确认修正，明确拒绝回滚，结果未知进入对账。

示例：未喜欢 → 点击喜欢 → 未完成时再点取消；最终目标为未喜欢。第一次请求晚到不能把 UI 又改成喜欢。离线时默认不自动排队远程写，提示需要联网；未来离线 mutation outbox 必须单独设计冲突和过期政策。

### 3.2 歌单编辑

前置：已登录、资源权限允许编辑、当前快照可识别。流程：读取最新摘要／revision → 用户编辑 → 串行提交 → 展示逐项结果 → 重新读取受影响部分。

- 创建成功但响应丢失：标记“结果待确认”，先查询候选结果，不自动再建一个。
- 删除：二次确认对象名和不可逆后果，避免“删除歌单”与“取消收藏”混用。
- 重命名／描述：验证空值、长度、编码；最终限制以接口契约为准。
- 增删／排序：按接口批次上限分块，记录成功、失败和未知项，失败不回滚服务端已经成功的部分假装全无变化。
- 排序以稳定 entryId／官方支持的 track 序列为依据，不上传 UI 行号。
- 无服务端 revision 时通过新快照指纹检测变化；无法安全合并则提示刷新并重做，不能声称强一致。
- 非本人歌单依据 permissions 禁用编辑；即使按钮已禁用，应用层仍验证权限。

## 4. 推荐、排行榜与私人 FM（FR-015～016）

推荐与榜单按范围、日期／周期、账号缓存；每日推荐的“天”以服务端语义为准，不用本机零点擅自换新。离线显示来源和缓存时间，不假装当天实时内容。

FM 维持少量前瞻条目（初值 2 首），一次补充请求；切换到普通队列要明确结束 FM 模式。不喜欢反馈是用户动作，与“网络失败自动跳过”不同；不得因解码失败发送不喜欢。补充失败后保留现有内容，耗尽时停止并提供重试。

## 5. 歌词（FR-021～022）

输入：TrackKey、官方歌词各语言／格式字段、媒体时钟。输出：规范化 LyricDocument 和当前 line/word index。

1. 获取后验证大小和编码，再按真实格式解析。
2. 解析支持行时间、多个时间标签、偏移、空行和无时间纯文本；翻译／音译按明确规则配对，不能只用数组下标强行对齐。
3. 重复或重叠时间保留多行；畸形片段可局部丢弃并记录解析警告，主体可用时不整页失败。
4. 逐字时间不可靠时降级逐行；缺少逐行时间再降级纯文本。
5. providerOffset 与 userOffset 不覆盖原文件，按 04 的正向延后规则合成。
6. 用户滚动暂时解除跟随，点击“返回当前歌词”恢复；切歌清理旧索引和动画。
7. 权限／接口失败、无歌词、纯音乐分别展示，不能靠一条空数组推断纯音乐。

歌词原始数据可按许可和缓存策略保存；导出歌词属于单独功能，不默认隐式上传或分享。

## 6. 下载与离线（FR-025～026）

**前置**：官方接口确认允许下载且获得所需资源；用户选择目录／授权。流媒体可播放不自动意味着可永久下载。

流程：创建任务 → 校验授权／空间／目录 → 解析下载源 → 写临时文件 → 校验完整性 → 原子发布或同目录安全替换 → DB 事务完成 → UI 标记可用。

- 临时文件与目标文件置于可原子 rename 的同一文件系统；跨文件系统移动先复制到目标侧临时文件，校验后再完成。
- 续传必须验证 Range、Content-Range、长度、ETag／版本及实际资源身份；收到 200 不得盲目追加到旧半文件。
- 签名 URL 过期重新解析后，若源质量／内容变化则重新下载，不拼接不同资源。
- 取消清理应用临时文件；暂停保留可恢复信息。磁盘不足、写权限丢失、目录撤销进入可解释失败。
- 文件名净化、防路径穿越和冲突；重复下载可复用经验证的同一授权资源，不能覆盖用户同名文件。
- 校验可用服务端 hash 或完整解码／长度信息；ETag 不当然是文件 MD5。校验强度在契约中说明。
- 已下载文件与账号／授权快照关联，离线可用策略由实际条款和接口定义；未知授权不得自行推导永久有效。
- 删除索引、删除文件、删除缓存是三个不同动作。清缓存不得移除用户主动下载。

重启后 Downloading/Verifying 任务先进入 Recovering，再验证文件与授权，不能直接显示已完成。默认不在应用刚启动时抢占带宽自动恢复全部任务，提供用户设置和清晰状态。

## 7. 本地音乐（FR-027）

用户主动选择目录或文件，通过 portal 或本地对话框授权。后台增量扫描支持取消，避免跟随符号链接形成环；不扫描整个 HOME，不读取与音乐无关的路径。

- 以 canonical location、文件大小和修改时间做快速检测，需要时再计算内容 hash。
- 标签解析有文件大小／嵌入封面像素限制；坏文件跳过并报告，不中止整个库。
- 缺少标签使用文件名作为显示回退，保留原始值和来源，不自动写回文件。
- 文件重命名／迁移通过显式重定位或 hash 辅助识别；网络文件系统断开不能当作永久删除。
- 本地搜索与在线搜索明确来源，可支持统一入口但不能暗中上传整个本地曲库。
- 可选的网易云匹配必须由用户启用，匹配结果作为关联候选，不覆盖本地身份和文件。

## 8. 历史与同步（FR-024）

本地历史、官方听歌历史和最近打开项目分开；接口未提供的细节不从本地事件伪装成官方结果。用户可以清理本地历史，并明确“清理本地不等于删除官方记录”。

官方播放上报只发送契约必需字段，遵守实际播放事实、频率和用户隐私说明。它与应用诊断遥测是不同数据流，默认无遥测不意味着关闭官方业务必需请求。

## 9. 云盘（FR-028～029）

M4 先实现列表、元数据和播放。云盘记录可能是账号私有，不进入公共元数据库，不把云盘 ID 当普通歌曲 ID。

M5 的上传需独立状态机：Preparing → Uploading → Finalizing → Indexing → Completed。断点能力以协议为准；传完字节不等于官方已入库。删除前显示名称和作用范围；匹配／修正保留原关联直到服务端确认。上传目的域、令牌、分块大小和提交超时均登记契约，禁止复用通用登录 Cookie 向不匹配域上传。

## 10. 评论与 MV（FR-030～032）

评论读取按资源类型、分页和排序缓存；内容按不可信文本处理，链接只允许受控打开。点赞与发表评论是不同 operation，写后审核状态不能伪装为立即公开成功。发帖／回复超时不能自动重复提交。

MV 播放与主音频播放器通过 PlaybackFocusService（到 M5 再引入）互斥。进入 MV 前保存音频上下文；返回时默认恢复到暂停状态，除非用户明确选择继续。视频后端、字幕、硬件解码及沙箱部署需独立 PoC，不因音频通过就认定视频支持。

## 11. 设置、导入导出与高级功能

- 设置保存前校验；切换输出设备失败保留原可用设备或进入暂停，不能写一个永远不可用的首选项却不说明。
- 重置设置不等于删除音乐库；账号退出不等于清空用户文件。
- 分享链接导入解析白名单官方 URL／ID，不执行任意 URL 或文件协议；导入歌单前展示数量、冲突和权限。
- 本地歌单导出使用带版本的开放结构，仅含需要的元数据／引用，不含 Cookie、签名 URL和私有绝对路径（除非用户明确选择）。
- 睡眠定时器采用单调计时，休眠后的行为需明确；DSP、gapless、crossfade 分别记录能力和测试，不能把不可实现选项预先放进稳定 UI。

## 12. 通用界面状态

每个页面必须同时设计：首次加载、局部加载、已有缓存刷新、真正空态、部分数据、可恢复错误、权限拒绝、离线和能力不支持。可重试动作保留用户输入；错误反馈靠近对应内容，不用全局 toast 代替所有解释。多项批量操作需显示真实成功比例及可重试项，不用一个“操作成功”掩盖部分失败。
