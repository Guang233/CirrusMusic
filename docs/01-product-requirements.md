# 01 · 产品范围与需求规格

> 基线 0.2 · 范围已按维护者要求更新：后端优先、UI 最后。需求描述目标，不代表 API 已支持；静态接口审计见 [api/](api/README.md)，真实契约仍待验证。

## 1. 产品定位

Cirrus 是“可靠播放优先、音乐库完整、与 Linux 桌面自然融合”的网易云第三方客户端。成功标准不是页面数量，而是用户可以长期用它完成找歌、听歌、整理和管理音乐的主要任务。

### 1.1 主要用户与场景

| 用户 | 场景 | 主要价值 |
| --- | --- | --- |
| 日常听歌用户 | 搜索歌曲、打开歌单、连续播放、查看歌词 | 稳定、响应快、音质与账号权限一致 |
| 音乐库重度用户 | 管理喜欢、歌单、收藏、播放队列、云盘 | 数据不丢、不串号、操作状态清晰 |
| Linux 桌面用户 | 媒体键、系统媒体控件、后台播放、多屏缩放 | 遵守桌面环境行为，不依赖某个桌面专有 hack |
| 本地音乐用户 | 扫描自选目录、播放本地文件、管理离线资源 | 无网络也可使用合法本地资源 |

### 1.2 范围解释

“几乎全部歌曲相关内容”转化为**可追踪的能力清单和分期交付**，而不是声称第三方客户端与官方服务永远等价。

范围内：账号、歌曲、搜索、专辑、歌手、歌单、首页推荐、**每日推荐歌曲**、排行榜、**私人 FM**、歌词、音质、播放队列、收藏、历史与真实播放上报、下载与本地音乐、云盘、歌曲／歌单／专辑评论和**一起听**。

维护者随后明确纳入播客／声音的消费端读取及后续播放；PodcastId／VoiceId独立于PlaylistId／SongId，不继承歌曲报告与权益语义。首包[搜索增量](api/entity-search-reads.md)之后，[消费详情／节目与4类recent读取](api/podcast-and-recent-reads.md)已合成接入；列表公开probe被-462拒绝，节目详情／真实recent和ProgramId↔VoiceId对应尚未实证，声音播放仍未交付。仍明确排除视频／MV、云贝、动态、云小编和创作者上传／审核工作台。私人 FM 仍是独立歌曲推荐能力。每日推荐歌曲可以用歌曲列表展示，但必须使用独立接口和来源模型。

其他非目标：直播、商城、票务、音乐人后台、会员购买支付、社交私信、K 歌创作、广告系统。第三方插件、皮肤市场、多音乐服务聚合不作为第一阶段架构负担。

明确不做：破解 DRM、伪造会员权限、解密受保护格式、绕过版权地区限制、未经授权批量搬运内容。

## 2. 优先级与发布口径

- **P0**：核心闭环及安全可靠性，稳定版不可缺少。
- **P1**：完整歌曲客户端的重要能力，目标在 M5 完整产品验收前完成；受接口或桌面限制时必须公开说明，经维护者批准才能降级。
- **P2**：增强能力，默认 M6；不阻塞首个稳定版，但保留在产品范围中。
- 表中阶段表示后端技术目标；可视交互／无障碍及完整 FR 的验收统一到 M5，不能把后端通过当产品已完成。阶段不是日历承诺，定义见[路线图](14-roadmap-and-backlog.md)。
- `API` 表示依赖真实接口，`平台` 表示依赖运行环境，`本地` 表示应用自身可实现。

## 5. 用户旅程与完成定义

**首听闭环**：启动应用 → 游客搜索／登录 → 查看歌曲 → 播放 → 调节音质和进度 → 查看歌词 → 加入队列。出现授权失败时显示真实原因，不循环刷接口。

**日常闭环**：恢复昨日队列但保持暂停 → 选择推荐／歌单 → 标记喜欢 → 在系统媒体控件切歌 → 退出后数据一致。

**离线闭环**：获得合法资源／导入本地文件 → 验证和入库 → 无网络启动 → 查找并播放可用内容 → 对失效授权明确提示。

一个需求完成必须同时满足：业务成功路径、失败／取消／空态、账号隔离、自动化或明确人工验收、必要无障碍检查、文档同步。截图和“我这里能播”都不足以独立证明完成。
