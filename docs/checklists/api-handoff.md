# 网易云官方 API 资料交接清单

> 用途：将维护者已有接口资料交给客户端开发使用。**不是要求终端用户配置 API，也不是要求另建服务。** 未勾选表示尚未提供／验证，不代表接口不存在。

## 1. 全局契约

- [x] 固定参考版本、来源和许可：见 [API 审计](../api/README.md)；变更需重新审计。
- [x] 全部 440 个模块的采用／待定／排除静态清单。
- [ ] 官方主机、方法、路径、不同协议类型与适用操作。
- [ ] 请求序列化、编码、加密／签名顺序、参数、随机源和测试向量。
- [ ] Cookie、CSRF、必要 headers、设备标识的要求和生命周期。
- [ ] 业务错误码、HTTP 状态关系、速率、批量上限与超时建议。
- [ ] 时间单位、时区、大整数 ID、空值与未知枚举约定。
- [ ] 脱敏成功／失败样例，禁止提交真实会话或私人数据。

## 2. M1/M2 必须验证的最小集合

- [ ] 首选登录：开始、轮询、到期、取消、额外验证。
- [ ] 会话校验与恢复；是否有刷新流程，不能凭空假定。
- [ ] 账号身份和权益字段。
- [ ] 游客／登录搜索、分页与建议（建议可稍后）。
- [ ] 歌曲详情，包括下架、试听和权限不足。
- [ ] 播放来源解析：音质、过期、必要 headers、CDN、重定向、Range/seek。
- [ ] 逐行歌词与可选翻译／音译／逐字格式。
- [ ] 真实授权音频样本，能在目标 Linux/Qt 后端验证。

缺少这些材料时只推进 fake 后端／本地播放，不编造正式接口。

## 3. M3 音乐库与发现

- [ ] 歌单完整 ID 序列／分页、顺序和重复策略。
- [ ] 创建／删除／修改／增删曲目／重排，部分失败与并发规则。
- [ ] 喜欢／收藏是 set 还是 toggle，是否可安全重试。
- [ ] 专辑与歌手列表、详情、收藏。
- [ ] 推荐／每日／榜单的账号范围、刷新周期、时区。
- [ ] 私人 FM 获取和用户反馈；自然播放与跳过上报区别。
- [ ] 官方历史／播放上报的必要字段、时机和真实性约束。

## 4. M4 文件与内容

- [ ] 下载接口是否独立、下载权限、URL 时效、Range、hash／ETag 语义。
- [ ] 离线资源可用／到期／续期规则，是否允许持久保存与导出。
- [ ] 云盘 ID、私有元数据、列表与播放来源。
- [ ] 评论列表、排序、分页、点赞和反滥用限制。

## 5. M3/M4 写操作与一起听

- [ ] 云盘上传、分块／续传、提交、入库、删除和匹配。
- [ ] 评论写、回复、删除本人评论、审核与重复提交语义。
- [ ] 一起听事件接收、心跳、时间基准、seq/version、成员权限与双端恢复。
- [ ] v2 浏览器 SDK token 的原生可行性；需要额外运行组件时先询问。
- [ ] 分享链接与导入形式（M6 扩展）。

视频、电台／播客、云贝、动态、云小编不在交接范围；私人 FM 明确保留。

## 6. 测试与安全交付

- [ ] 专用测试账号或维护者代为执行的真实验证流程，不在仓库存凭据。
- [ ] 不同权益、无权限、空结果、已删除资源的可重复样本。
- [ ] 签名固定向量与脱敏请求／响应，不只是一次成功截图。
- [ ] operation 登记模板填写完整，并关联 FR 与 TC。
- [ ] 明确哪些资料可公开，哪些只保存摘要／引用。
- [ ] 未验证项目列入 Q/R，注明负责人和验证节点。

交接完成的最小证据：契约登记 + 可重跑 fixture 测试 + 最近一次受控真实验证记录。所有生产端点仍由应用内置适配器管理。
