> 适用于 M4 稳定版与后续正式发布。Alpha/Beta 可缩减范围但必须标明；安全与数据破坏类门禁不可跳过。

- 支持的桌面／架构／包格式：待填写
- 负责人／验证者／日期：待填写
- 测试报告／构建日志／产物／签名位置：待填写

## 范围与功能

- [ ] 所有本版 P0 通过并有 TC 证据。
- [ ] 目标 P1 通过；未交付项有维护者批准的降级说明。
- [ ] P2／实验能力不冒充正式支持，UI 按 capability 展示。
- [ ] 安装后直接调用内置官方 API，无用户端点配置／额外代理要求。
- [ ] 登录→搜索→播放→歌词→喜欢→歌单→退出恢复端到端通过。
- [ ] 高级音质、下载和离线的实际权限／降级准确呈现。

## 播放、并发与恢复

- [ ] 1,000 次随机切歌无串歌，8 h 稳态播放无非预期停播／崩溃。
- [ ] 暂停中加载、切换音质、seek、重复结束事件、坏源有限跳过通过。
- [ ] 队列随机／循环／重复歌曲／当前项删除与恢复一致。
- [ ] 断网、过期来源、休眠、无设备、蓝牙断开有可解释恢复。
- [ ] 启动恢复默认不自动出声，退出不丢最近有效快照。

## 数据与安全

- [ ] 换号／登出后旧请求不写入新账号，私有缓存不跨 profile。
- [ ] 密钥环拒绝时无明文 fallback；仓库／产物／日志无凭据。
- [ ] TLS 校验、域名／重定向、URL 脱敏和下载路径检查通过。
- [ ] 非幂等写超时不重复提交，部分成功和不确定结果有对账。
- [ ] 每个支持的旧 DB 升级通过；高版本拒写与一致备份可恢复。
- [ ] 下载崩溃窗口、磁盘满、Range 变化、文件丢失测试通过。
- [ ] 清缓存不删除用户下载；删账号数据的范围明确。
- [ ] 诊断包需用户主动导出并可预览，默认无遥测。

## UI 与平台

- [ ] 亮／暗／系统主题、长中英文、100/125/150/200% 缩放通过。
- [ ] 主要流程可键盘完成；IME、Orca、焦点、对比度通过。
- [ ] 大列表和播放页满足性能预算，低图形能力有降级。
- [ ] GNOME Wayland、KDE Wayland 和至少一个 X11 场景通过。
- [ ] MPRIS 微秒／TrackId／Seeked／能力正确，媒体键不双触发。
- [ ] 无托盘仍能正常关闭退出；portal 缺能力／拒绝时有降级。
- [ ] 沙箱文件授权、密钥环、设备和封面系统展示真实可用。

## 工程与发布包

- [ ] 格式、lint、单元、契约、存储、QML 和 sanitizer 门禁通过。
- [ ] 最近一次核心真实官方 API 冒烟通过，非仅 mock。
- [ ] 干净机器安装和升级通过，运行不依赖开发版 Qt 或私有文件。
- [ ] 运行包包含必要 QML／platform／图片／音频插件，不含测试秘密。
- [ ] Runtime、依赖版本和哈希固定，可追溯重建。
- [ ] app ID、desktop、图标、AppStream、包 ID 一致。
- [ ] 最小权限审查完成；新增权限在发布说明中解释。
- [ ] 自身 LICENSE、依赖许可、字体／图标／媒体素材 attribution、SBOM 齐全。
- [ ] 产物签名／可信校验、更新与回退说明、安全报告渠道可用。
- [ ] 无 S0/S1；剩余问题具备影响面、负责人和下一版本计划。
- [ ] README、需求覆盖、ADR、路线图和已知限制与代码一致。
